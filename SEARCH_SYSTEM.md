# Calculator Search System Documentation

## Overview

The calculator search functionality has been updated to be completely dynamic and automatic. No manual maintenance is required when adding new calculators.

## How It Works

### Previous System (Fixed)
- Used a static `search-data.js` file with hardcoded calculator entries
- Required manual updates every time a new calculator was added
- Led to missing calculators in search results

### New System (Current)
- Uses Jekyll templating to automatically generate search data from actual calculator files
- Scans all calculator pages in the repository and extracts their information
- Updates automatically when the site builds on GitHub Pages

## Technical Implementation

### Search Data Generation
The search data is generated by `assets/js/search-data.js` which is now a Jekyll template that:

1. **Ukrainian Calculators**: Finds all pages in `/calculators/` directory
   - Filters out the main `/calculators/` index page
   - Excludes category pages (`/categories/`)
   - Excludes English pages (containing `/en/`)

2. **English Calculators**: Finds all pages in `/en/calculators/` directory
   - Includes all calculator pages in the English section

3. **Data Structure**: For each calculator, extracts:
   - `title`: From the page's front matter
   - `url`: The page's URL
   - `filename`: Extracted from the URL (used for internal reference)

### Search Functionality
The search JavaScript in `assets/js/main.js`:
- Loads the dynamically generated search data
- Performs case-insensitive searches across calculator titles
- Supports both Ukrainian and English based on the current page language
- Provides keyboard navigation and auto-complete functionality

## Adding New Calculators

### For Developers
When adding a new calculator:

1. **Create the calculator file** (e.g., `calculators/my-new-calculator.md` for Ukrainian or `en/calculators/my-new-calculator.md` for English)

2. **Add proper front matter**:
   ```yaml
   ---
   layout: calculator
   title: "Your Calculator Title"
   categories: [category]
   # ... other front matter
   ---
   ```

3. **That's it!** The calculator will automatically appear in search results after the next site build.

### No Manual Steps Required
- ❌ No need to update search-data.js
- ❌ No need to update any search configuration
- ❌ No need to manually add entries anywhere

## Verification

### Testing Search Functionality
1. Visit the main site or any page with the search box
2. Type part of your calculator's title
3. It should appear in the search results immediately

### Debug Tools
- Visit `/test-search.html` for debug information
- Shows total calculator counts and lists missing/found calculators
- Useful for troubleshooting search issues

## Future Maintenance

This system requires **zero maintenance**. As long as new calculators follow the standard file structure and include proper front matter, they will automatically be included in search results.

The only scenario requiring attention would be if:
- The site structure changes significantly
- The Jekyll build process changes
- The search functionality itself needs updates

In such cases, only the Jekyll template in `assets/js/search-data.js` would need updating.

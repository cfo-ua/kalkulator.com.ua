Калькулятор ґрунту для грядок

Розрахуйте необхідну кількість ґрунту для високих грядок та контейнерного садівництва. Цей калькулятор допоможе оцінити об'єм ґрунтової суміші, компосту та добрив для успішного вирощування.

Типи ґрунтових сумішей:

  • Універсальна суміш: торф + компост + пісок (2:2:1)
  • Для овочів: перегній + садова земля + торф (1:1:1)
  • Для трав: дернова земля + пісок + компост (3:1:1)
  • Для квітів: листова земля + торф + перліт (2:1:1)
  • Для розсади: торф + вермикуліт + компост (2:1:1)

Рекомендована глибина для культур:

  • Зелень (салат, шпинат): 15-20 см
  • Редиска, цибуля: 20-25 см
  • Морква, буряк: 30-35 см
  • Капуста, перець: 35-40 см
  • Томати, огірки: 40-50 см
  • Картопля: 40-60 см

Компоненти ґрунтової суміші:

  • Торф: покращує структуру, утримує вологу
  • Компост: живлення, корисна мікрофлора
  • Перегній: органічні речовини, азот
  • Пісок: дренаж, аерація
  • Вермикуліт: розпушування, утримання вологи
  • Кокосове волокно: екологічна альтернатива торфу

Вартість компонентів (за м³):

  • Готова суміш універсальна: 2000-3000 грн
  • Торф нейтралізований: 1500-2200 грн
  • Компост зрілий: 1200-1800 грн
  • Перегній кінський: 2500-3500 грн
  • Біогумус: 4000-6000 грн
  • Пісок річковий: 800-1200 грн

Показники якісного ґрунту:

  • pH: 6.0-7.0 (нейтральний або слабокислий)
  • Вологість: добре утримує, але не заболочується
  • Структура: розсипчастий, без грудок
  • Колір: темний, багатий органікою
  • Запах: приємний земляний

Додаткові компоненти:

  • Вапно: для зниження кислотності
  • Сірка: для підвищення кислотності
  • Перліт: покращення дренажу
  • Деревне вугілля: абсорбент, профілактика гнилі

Сезонність закупівель:

  • Весна (березень-квітень): пік попиту, високі ціни
  • Літо: стабільні ціни, хороша якість
  • Осінь: знижки, підготовка до наступного сезону
  • Зима: найкращі ціни, обмежена наявність

Поширені питання

Скільки ґрунту потрібно для грядки 2×1×0.3 метра?
Для грядки 2×1×0.3 м потрібно 0.6 м³ ґрунту. Це приблизно 12 мішків по 50 літрів.
Чи можна змішувати садову землю з покупною?
Так, можна змішувати у пропорції 1:1. Садова земля додає мікроорганізми, покупна - структуру та живлення.
Як часто потрібно міняти ґрунт у високих грядках?
Повністю - раз на 3-5 років. Щорічно додавайте 5-10 см компосту або перегною.
Який ґрунт найкращий для томатів?
Суміш перегною, торфу та садової землі (1:1:1) з додаванням деревної золи.
Чи потрібен дренаж у високих грядках?
Так, на дно покладіть 5-10 см дренажу (галька, керамзит) для запобігання застою води.
Скільки коштує заповнити грядку 3×1.5×0.4 м?
Об'єм 1.8 м³. Готовою сумішшю: 3600-5400 грн. Самостійне змішування: 2500-4000 грн.

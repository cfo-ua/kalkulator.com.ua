Калькулятор тротуарної плитки

Розрахуйте точну кількість тротуарної плитки для вашого патіо, доріжки або під'їзду. Цей професійний калькулятор бруківки оцінює плитку, основні матеріали, пісок і вартість укладання.

Як розрахувати потребу в плитці:

  1. Виміряйте площу: довжина × ширина зони мощення
  2. Оберіть розмір плитки: популярні розміри та візерунки
  3. Додайте запас: 5-10% на обрізки та бій
  4. Розрахуйте основні матеріали: шари щебеню та піску

Популярні розміри плитки та покриття:

  • 100×200 мм цеглинка: 50 шт/м²
  • 200×200 мм квадрат: 25 шт/м²
  • 300×300 мм великий квадрат: 11 шт/м²
  • 400×400 мм плита: 6,25 шт/м²
  • 500×500 мм велика плита: 4 шт/м²
  • Фігурна "Хвиля": 40-45 шт/м²

Шари основи під плитку:

  • Піщана подушка: 30-50 мм товщина
  • Щебеневе підґрунтя: 100-150 мм товщина
  • Геотекстиль: між шарами для стабільності
  • Бордюр: для утримання країв

Вартість матеріалів (орієнтовна):

  • Бетонна плитка: 250-450 грн/м²
  • Клінкерна цегла: 800-1500 грн/м²
  • Гранітна бруківка: 1200-2500 грн/м²
  • Пісок для укладання: 800-1200 грн/м³
  • Щебінь фракції 5-20: 1000-1500 грн/м³
  • Геотекстиль: 35-60 грн/м²

Типи тротуарної плитки:

  • Вібропресована: економична, для доріжок
  • Вібролита: декоративна, різні кольори
  • Клінкерна: преміум, морозостійка
  • Гранітна: найдовговічніша, для навантажень

Схеми укладання:

  • "Цеглинка": зміщення на половину довжини
  • "Ялинка": під кутом 45° або 90°
  • "Плетінка": поперемінні напрямки
  • "Випадкова": хаотичне розміщення

Поради щодо укладання:

  • Підготовка основи: найважливіший етап
  • Дренаж: передбачте відвід води
  • Ущільнення: кожен шар ретельно утрамбуйте
  • Заповнення швів: пісок або спеціальні суміші

Поширені питання

Скільки плитки потрібно для під'їзду 4×6 метрів?
Для під'їзду 4×6 м (24 м²) плиткою 200×200 мм: 600 штук + 5% запас = 630 штук.
Яка товщина плитки для під'їзду автомобіля?
Для автомобільного під'їзду мінімум 60 мм товщина. Для вантажівок - 80-100 мм.
Скільки піску потрібно під тротуарну плитку?
На піщану подушку 40 мм: 0,04 м³ на 1 м² площі. Для 20 м² = 0,8 м³ піску.
Чи потрібен геотекстиль під плитку?
Рекомендується для запобігання прорастанню бур'янів і стабілізації основи, особливо на глинистих ґрунтах.
Скільки коштує укладання тротуарної плитки в Україні?
Робота по укладанню: 150-300 грн/м² залежно від складності схеми та регіону.
Як розрахувати кількість бордюрів?
Виміряйте периметр зони мощення. Стандартний бордюр 1000×200×80 мм покриває 1 м периметра.

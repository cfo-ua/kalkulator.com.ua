Калькулятор розміру грудей і бюстгальтера онлайн

Не впевнені, який розмір бюстгальтера або одягу обрати? Введіть свої параметри тіла, і наш калькулятор розміру грудей підкаже, який міжнародний розмір (UA, EU, US, UK, INT) вам підходить для бюстгальтера та одягу.

Як працює калькулятор розміру грудей?

Ви вводите точні виміри:

  • Обхват грудей (у сантиметрах) — вимірюється по найповнішій частині грудей
  • Обхват під грудьми — для точного підбору розміру бюстгальтера
  • Обхват талії — для одягу
  • Обхват стегон — для нижньої частини одягу

І отримуєте рекомендовані розміри:

  • Розмір бюстгальтера (75A, 80B, 85C тощо)
  • Міжнародні розміри одягу (XS, S, M, L, XL)
  • Європейські (EU)
  • Українські (UA)
  • Американські (US)
  • Британські (UK)

Особливості калькулятора розміру грудей

  • Точний підбір бюстгальтера — розрахунок чашки (A, B, C, D, DD) та обхвату
  • Підходить для жінок і чоловіків
  • Враховує особливості різних систем розмірів
  • Корисно при покупках в іноземних інтернет-магазинах
  • Допомагає уникнути помилок при онлайн-шопінгу

Як правильно виміряти обхват грудей?

  1. Обхват грудей: Вимірюйте стрічкою по найповнішій частині грудей, тримаючи стрічку паралельно підлозі
  2. Обхват під грудьми: Вимірюйте безпосередньо під грудьми, щільно, але не перетягуючи
  3. Одягніть правильний бюстгальтер: Для точних вимірів одягніть підходящий бюстгальтер без push-up

Увага: розміри бюстгальтерів та одягу можуть відрізнятися в залежності від бренду, фасону або країни виробництва. Завжди звіряйтесь із таблицею розмірів на сайті продавця.

Поширені питання

Як працює калькулятор розміру грудей?
Він використовує ваші параметри тіла — обхват грудей, під грудьми, талії та стегон — щоб підібрати відповідний розмір бюстгальтера та одягу у міжнародних системах (INT, EU, UA, US, UK).
Як правильно виміряти обхват грудей для бюстгальтера?
Вимірюйте обхват грудей по найповнішій частині в правильному бюстгальтері. Обхват під грудьми вимірюйте щільно під грудьми. Стрічка має бути паралельна підлозі.
Чому можуть бути відмінності в розмірі бюстгальтера?
Розміри можуть змінюватися залежно від бренду, типу бюстгальтера (push-up, без кісточок) або країни виробника. Форма чашки також може впливати на посадку.
Які одиниці виміру потрібно вводити?
Усі параметри вводяться в сантиметрах (см). Це стандартна одиниця для підбору розмірів бюстгальтерів та одягу у більшості країн.
Чи підходить калькулятор для різних типів бюстгальтерів?
Так. Калькулятор підходить для більшості типів бюстгальтерів, але пам'ятайте, що спортивні бюстгальтери та моделі з push-up можуть мати особливості розміру.
Як розрахувати розмір чашки бюстгальтера?
Розмір чашки розраховується як різниця між обхватом грудей та обхватом під грудьми. Кожні 2.5 см різниці відповідають одному розміру чашки (A, B, C, D тощо).

Калькулятор добової норми калорій

Калькулятор добової норми калорій (TDEE/BMR, підрахунок калорій онлайн)

Онлайн калькулятор калорій допоможе вам швидко та точно визначити добову норму калорій для схуднення, набору ваги чи підтримки маси. Враховується ваш вік, стать, ріст, вага, рівень активності та бажана ціль. Підрахунок калорій — це основа здорового харчування, контролю ваги та досягнення фітнес-цілей.

  • Вкажіть стать, вік, зріст, вагу та рівень фізичної активності.
  • Обирайте ціль: схуднення (дефіцит калорій), підтримка ваги або набір маси.
  • Дізнайтесь індивідуальну норму калорій на день, розрахунок дефіциту чи надлишку калорій.
  • Отримайте рекомендації по білках, жирах, вуглеводах (макроси) для вашої мети.
  • Додатково: калькулятор калорій для їжі, підрахунок калорій онлайн, формули розрахунку, таблиці споживання.

Що таке BMR та TDEE?

BMR (Basal Metabolic Rate) — це базальний обмін речовин, тобто кількість калорій, яку організм витрачає у стані спокою.
TDEE (Total Daily Energy Expenditure) — це загальні добові витрати енергії з урахуванням руху та фізичного навантаження. Саме TDEE показує, скільки калорій потрібно для підтримки поточної ваги.

Навіщо рахувати калорії?

Підрахунок калорій — це дієвий спосіб досягти фітнес-цілей: схуднення, набору або підтримки ваги. Калькулятор калорійності допоможе уникнути помилок, дає чітке розуміння, скільки і чого потрібно їсти.

Розрахунок калорій для схуднення

Для схуднення потрібно створити дефіцит калорій — споживати менше калорій, ніж витрачаєте. Рекомендовано знижувати калорійність раціону на 10-20% від TDEE або мінус 300-500 ккал на добу. Не рекомендується зменшувати споживання нижче базального обміну (BMR).

Розрахунок калорій для набору ваги

Для набору маси потрібно створити надлишок калорій — споживати більше калорій, ніж витрачаєте. Зазвичай збільшують раціон на 10-20% від вашого TDEE.

Розподіл макронутрієнтів (білки, жири, вуглеводи)

  • Білки: 1.5–2 г на 1 кг ваги
  • Жири: 0.8–1 г на 1 кг ваги
  • Вуглеводи: решта калорій
Калькулятор автоматично підкаже оптимальне співвідношення для досягнення вашої мети.

Як користуватись калькулятором калорій?

  1. Вкажіть особисті дані: стать, вік, зріст, вага
  2. Виберіть рівень фізичної активності
  3. Оберіть вашу мету: схуднення, підтримка, набір
  4. Отримайте точний розрахунок норми калорій, білків, жирів і вуглеводів
  5. Використовуйте підказки для складання меню (раціон на день/тиждень)

Поширені питання

Яка формула використовується для розрахунку калорій (BMR, TDEE)?
Використовується формула Mifflin-St Jeor для BMR (основного обміну речовин), множення на відповідний коефіцієнт активності для розрахунку TDEE (total daily energy expenditure).
Що таке добова норма калорій?
Це кількість калорій, яку ви маєте споживати щодня для підтримки поточної ваги. Для схуднення необхідно дефіцит калорій, для набору — надлишок.
Як вибрати рівень фізичної активності у калькуляторі?
Сидячий — мінімум руху, легкий — 1-3 тренування на тиждень, середній — 3-5, високий — 6+, дуже високий — щоденні тренування або важка фізична праця. Виберіть варіант, який відповідає вашому способу життя.
Який дефіцит калорій оптимальний для схуднення?
Рекомендується дефіцит 10-20% від TDEE або на 300-500 ккал менше від вашої добової потреби, щоб худнути без шкоди для здоров'я.
Як розрахувати калорії для набору ваги чи маси?
Для набору маси рекомендується збільшити калорійність на 10-20% від TDEE. Важливо контролювати набір жиру, а не тільки ваги.
Чи враховує калькулятор калорій калорійність їжі?
Так, калькулятор дозволяє розрахувати калорійність їжі, страв, а також підрахувати добову норму калорій з урахуванням вашого меню.
Що таке калькулятор БЖУ?
Калькулятор БЖУ підраховує добову норму білків, жирів і вуглеводів залежно від вашої мети. Це допоможе скласти збалансований раціон.
Чи можна використовувати калькулятор калорій для дітей чи підлітків?
Розрахунок калорій для дітей та підлітків може відрізнятись, адже організм росте. Для них рекомендовано консультуватися з лікарем чи дієтологом.
Чи підходить калькулятор для спортсменів?
Так, калькулятор враховує високий рівень активності та дає рекомендації по макросах для тих, хто тренується інтенсивно або займається спортом.
Які типові помилки при підрахунку калорій?
Часті помилки: недооцінка порцій, ігнорування перекусів, неправильний вибір рівня активності, занадто великий дефіцит калорій або надлишок.
Що робити, якщо вага не змінюється, хоча я дотримуюсь розрахунків?
Можливі причини: неточний підрахунок калорій, зміни у фізичній активності, гормональні причини, затримка води. Перевірте точність даних, змініть стратегію, зверніться до фахівця.

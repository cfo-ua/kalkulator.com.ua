Поширені питання

Як правильно виміряти розміри картини для рамки?
Виміряйте точні розміри самого зображення (без рамки). Для полотен вимірюйте видиму частину, для фотографій — розмір друку. Завжди додавайте 2-3 мм для вільного вкладання.
Яка оптимальна ширина паспарту?
Стандартна ширина паспарту складає 5-8 см для невеликих робіт (до 30 см) та 8-15 см для великих. Нижній край паспарту зазвичай робиться на 0.5-1 см ширшим за верхній та бокові.
Чи потрібно паспарту для всіх типів зображень?
Паспарту не обов'язкове, але рекомендується для фотографій, акварелей та графіки. Воно створює повітряність та захищає зображення від контакту зі склом.
Як вибрати колір паспарту?
Найбезпечніші варіанти — білий, кремовий або сірий. Кольорове паспарту використовуйте обережно, воно має доповнювати, а не конкурувати із зображенням.
Які матеріали краще для рамки?
Для цінних робіт використовуйте архівні матеріали — безкислотне паспарту та УФ-захисне скло. Для декоративних цілей підійдуть стандартні матеріали.
На якій висоті вішати картини?
Центр картини має бути на рівні очей — приблизно 150-165 см від підлоги. Для групового розміщення тримайте центральну лінію.
Як розрахувати відстань між картинами на стіні?
Оптимальна відстань між рамками — 5-15 см залежно від розмірів. Для великих картин можна збільшити до 20-30 см.

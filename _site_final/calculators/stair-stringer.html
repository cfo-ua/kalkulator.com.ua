Калькулятор сходових тетив

Розрахуйте точні розміри сходових тетив і планування для будівництва безпечних сходів, що відповідають нормам. Цей професійний калькулятор тетив надає розміри для розрізів, кути та потребу в матеріалах.

Основи сходових тетив:

  • Тетиви: несучі конструкції, що несуть навантаження сходів
  • Типовий крок: 400 мм по центрах, максимум 600 мм
  • Матеріал: дошка 50×300 мм для прольотів до 4 метрів
  • Кількість: 3 тетиви для сходів шириною до 1 метра

Вимоги будівельних норм:

  • Висота підсходинки: 120 мм мінімум, 190 мм максимум
  • Глибина проступу: 250 мм мінімум (житлові)
  • Відхилення: ±10 мм між підсходинками і проступами
  • Висота проходу: 2000 мм мінімум вільної висоти

Рекомендовані розміри:

  • Комфортні підсходинки: 150-170 мм
  • Комфортні проступи: 280-320 мм
  • Формула комфорту: 2h + b = 600-650 мм
  • Кут нахилу: 30-35° оптимально

Матеріали та вартість:

  • Тетиви (50×300×4000): 800-1200 грн за штуку
  • Проступи (40 мм товщина): 1000-1500 грн/м²
  • Підсходинки (20 мм): 600-900 грн/м²
  • Крізьплення: саморізи, кронштейни, клей

Інструменти для роботи:

  • Розмітка: кутник, рівень, рулетка
  • Розрізання: циркулярна пила, лобзик
  • З'єднання: дриль, шуруповерт
  • Обробка: рубанок, шліфмашина

Поширені питання

Скільки тетив потрібно для сходів шириною 1 метр?
Для сходів шириною 1 м потрібно 3 тетиви: дві по краях і одна по центру. Це забезпечує надійну підтримку та запобігає прогину проступей.
Який оптимальний кут нахилу сходів?
Оптимальний кут нахилу для житлових сходів 30-35°. Менше 30° - занадто пологі, більше 40° - занадто круті для комфортного використання.
Як розрахувати висоту підсходинки?
Розділіть загальну висоту на бажану кількість сходинок. Оптимальна висота підсходинки 150-170 мм для комфортного підйому.
Чи можна використовувати дошку 50×250 для тетив?
Для коротких прольотів (до 3 м) можна, але краще використовувати 50×300 мм для забезпечення достатньої міцності та жорсткості конструкції.
Скільки коштує зробити дерев'яні сходи самостійно?
Самостійне виготовлення коштує 3000-8000 грн за погонний метр, в залежності від породи дерева та складності конструкції.
Яка мінімальна ширина сходів?
Мінімальна ширина 700 мм для одного напряму руху, рекомендовано 900-1200 мм для комфортного користування.

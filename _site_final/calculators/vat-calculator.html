Калькулятор ПДВ

Введіть будь-які два значення — калькулятор автоматично визначить третє. Ви можете розрахувати:

  • Ціну з ПДВ, знаючи ставку та ціну без ПДВ
  • Ціну без ПДВ, знаючи ставку та ціну з ПДВ
  • Ставку ПДВ, якщо відомі обидві ціни

Як користуватися калькулятором ПДВ

  1. Вкажіть ставку ПДВ (наприклад, 20%, 7% або 0%)
  2. Введіть відому суму — з ПДВ або без ПДВ
  3. Калькулятор миттєво обчислить третє значення

Формули розрахунку ПДВ

  • Ціна з ПДВ = Ціна без ПДВ × (1 + ставка / 100)
  • Ціна без ПДВ = Ціна з ПДВ / (1 + ставка / 100)
  • Сума ПДВ = Ціна з ПДВ - Ціна без ПДВ

Що таке ПДВ?

ПДВ (податок на додану вартість) — це непрямий податок, який нараховується на товари та послуги на кожному етапі постачання. В Україні основна ставка ПДВ становить 20%, але також існують знижені ставки: 7% (наприклад, на ліки), 0% (на експорт).

Приклади розрахунку ПДВ

  • Нарахування ПДВ: якщо сума без ПДВ 1000 грн, ставка 20% ⇒ ціна з ПДВ = 1000 × 1.2 = 1200 грн
  • Виділення ПДВ: якщо ціна з ПДВ 1200 грн, ставка 20% ⇒ ціна без ПДВ = 1200 / 1.2 = 1000 грн, ПДВ = 200 грн
  • Зворотній розрахунок: якщо знаєте обидві ціни, ставка = ((Ціна з ПДВ / Ціна без ПДВ) - 1) × 100%

Навіщо використовувати онлайн калькулятор ПДВ?

Цей інструмент зручний для бухгалтерів, підприємців, ФОПів, покупців і продавців. Він дозволяє швидко та точно:

  • розділити суму на ПДВ і базову частину
  • перевірити правильність нарахування податку
  • скористатись ставками 7%, 20%, 0%
  • застосовувати до будь-якої сфери: покупки, послуги, торгівля, імпорт/експорт

Калькулятор ПДВ з розшифровкою суми

Після розрахунку ви побачите повну розшифровку: сума без ПДВ, сума ПДВ, загальна вартість. Це дозволяє краще контролювати витрати та формувати звітність.

Поширені питання

Яка стандартна ставка ПДВ в Україні?
Зазвичай 20%. Для деяких товарів та послуг можуть діяти пільгові ставки — 7% або 0%.
Як розрахувати ПДВ з ціни з ПДВ?
Сума ПДВ = Ціна з ПДВ - (Ціна з ПДВ / (1 + ставка / 100))
Як розрахувати ціну з ПДВ?
Ціна з ПДВ = Ціна без ПДВ × (1 + ставка / 100)

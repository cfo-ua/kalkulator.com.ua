Калькулятор сходів

Розрахуйте ідеальні розміри сходів для безпечних, комфортних та відповідних будівельним нормам сходових маршів. Цей професійний калькулятор визначає висоту сходинки (підйом), глибину проступу (хід) та загальну кількість сходинок.

Як використовувати калькулятор сходів:

  1. Виміряйте загальний підйом: вертикальна відстань від нижнього до верхнього поверху
  2. Виміряйте загальний хід: горизонтальний простір, доступний для сходів
  3. Введіть ваші виміри для отримання оптимальних розмірів сходинок
  4. Скорегуйте за потреби відповідно до будівельних норм та стандартів комфорту

Стандарти безпечних розмірів сходів:

  • Ідеальна висота підйому: 15-19 см
  • Ідеальна глибина проступу: 25-28 см
  • Максимальний підйом: 19 см для житлових, 17 см для комерційних
  • Мінімальний проступ: 25 см для житлових, 28 см для комерційних
  • Однакові розміри: всі сходинки мають бути ідентичними ±1 см

Вимоги будівельних норм:

  • Висота проходу: мінімум 2,0 м вертикального просвіту
  • Висота поручнів: 85-95 см над краєм проступу
  • Ширина сходів: мінімум 90 см для житлових
  • Майданчики: обов'язкові зверху та знизу, мінімум 90 см глибиною

Формули проектування сходів:

  • Підйом + Хід = 43-46 см (формула комфортної ходьби)
  • 2 × Підйом + Хід = 60-64 см (формула оптимальних пропорцій)
  • Кількість сходинок = Загальний підйом ÷ Висота сходинки
  • Загальний хід = (Кількість сходинок - 1) × Глибина проступу

Поширені застосування сходів:

  • Внутрішні сходи: основні сходи, доступ до підвалу, горищні сходи
  • Зовнішні сходи: сходи ґанку, сходи терас, садові сходи
  • Комерційні сходи: офісні будівлі, торгові приміщення
  • Промислові сходи: доступ до складів, платформи обладнання

Поради з планування матеріалів:

  • Косоури сходів: зазвичай дошка 50×300 мм для прольотів до 4,2 м
  • Проступи: твердолистяна дошка 32 мм або дошка 50 мм з порожком
  • Підйоми: фанера 18 мм або твердолистяна дошка (може бути відкритим в деяких дизайнах)
  • Кріплення: оцинковані болти, будівельний клей, оздоблювальні цвяхи

Типи сходів:

  • Прямі сходи: найпростіші в будівництві, економні
  • Г-подібні сходи: з поворотом на 90°, з майданчиком
  • П-подібні сходи: з поворотом на 180°, компактні
  • Гвинтові сходи: для обмежених просторів
  • Забіжні сходи: з клиноподібними сходинками на поворотах

Поширені питання

Яка ідеальна висота сходинки для сходів?
Ідеальна висота підйому 15-19 см. Це забезпечує комфортний підйом для більшості людей, відповідаючи будівельним нормам. Нижчі сходинки легше піднімати, але потребують більше сходинок.
Як розрахувати кількість необхідних сходинок?
Поділіть ваш загальний підйом на бажану висоту сходинки. Наприклад: 270 см загальний підйом ÷ 18 см сходинка = 15 сходинок. Потім перерахуйте: 270 см ÷ 15 сходинок = 18 см фактична висота сходинки.
Що робити, якщо мої сходи не вміщуються в простір?
Ви можете: 1) Скорегувати кут сходів (крутіший/пологіший), 2) Додати майданчик для зміни напрямку, 3) Використати забіжні сходинки для поворотів, або 4) Розглянути гвинтові або альтернативні сходи для екстремально обмежених просторів.
Чи всі сходинки мають бути точно однакового розміру?
Так! Будівельні норми вимагають однакової висоти підйому в межах ±1 см та однакової глибини проступу в межах ±1 см. Неоднакові сходинки створюють небезпеку спотикання.
Чи можу я будувати сходи крутіші за стандартні розміри?
Будівельні норми встановлюють максимальну висоту підйому з міркувань безпеки. Для дуже крутого доступу (як корабельні трапи) можливо потрібне спеціальне схвалення або альтернативні рішення.
Скільки простору потрібно зверху та знизу сходів?
Потрібні майданчики мінімум 90 см глибиною зверху та знизу. Ширина майданчика має бути принаймні такою ж широкою, як ширина сходів (мінімум 90 см для житлових).

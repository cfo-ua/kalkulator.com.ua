What are trigonometric functions?

Trigonometric functions relate the angles of a triangle to the lengths of its sides. They are fundamental in mathematics, physics, and engineering.

Basic trigonometric functions:

  • sin(θ) = opposite / hypotenuse
  • cos(θ) = adjacent / hypotenuse
  • tan(θ) = opposite / adjacent = sin(θ) / cos(θ)
  • cot(θ) = adjacent / opposite = cos(θ) / sin(θ) = 1 / tan(θ)

Common angle values:

  • 0°: sin = 0, cos = 1, tan = 0
  • 30°: sin = 0.5, cos = 0.866, tan = 0.577
  • 45°: sin = 0.707, cos = 0.707, tan = 1
  • 60°: sin = 0.866, cos = 0.5, tan = 1.732
  • 90°: sin = 1, cos = 0, tan = ∞

Frequently Asked Questions

What unit system should I use for angles?
Enter angles in degrees (0 - 360°).
What is cot?
cot(x) = 1 / tan(x), which is the cotangent function.
What are the main trigonometric identities?
sin²(x) + cos²(x) = 1, tan(x) = sin(x) / cos(x), cot(x) = cos(x) / sin(x).
What is trigonometry used for?
Trigonometry is used in geometry, physics, construction, navigation, and engineering applications.
Why do some functions show infinity (∞)?
When cos(x) = 0, tan(x) becomes infinite. When sin(x) = 0, cot(x) becomes infinite.

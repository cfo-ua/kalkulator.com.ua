Калькулятор квадратного рівняння

Введіть коефіцієнти a, b, c для рівняння ax² + bx + c = 0 і дізнайтеся розвʼязки.

Поширені питання

Як знайти корені квадратного рівняння?
Використовуйте формулу дискримінанта: x = (-b ± √D) / 2a, де D = b² - 4ac.
Що таке дискримінант?
Дискримінант — це вираз b² - 4ac, який визначає кількість розвʼязків рівняння.

What is a derivative?

A derivative shows how fast a function's value changes. In school mathematics, it's the foundation for analyzing graphs, finding maxima/minima, velocity in physics, tangent slopes, etc.

Who will find this online derivative calculator useful?

  • Students for checking algebra, calculus and exam problems.
  • Teachers — for creating examples and checking answers.
  • Anyone who wants to find function derivative online quickly and error-free.

What does the derivative function calculator support?

You can enter:

  • Polynomials: x^2, x^3 + 2*x
  • Trigonometric functions: sin(x), cos(x), tan(x)
  • Logarithms: ln(x), log(x + 1)
  • Exponentials: e^x, exp(x)
  • Complex expressions: x * sin(x), ln(x^2 + 1), sqrt(x), abs(x)

Frequently Asked Questions

What is a function derivative?
A function derivative is a new function that shows the rate of change of the original function. It's used for finding extrema, graph analysis, and studying function behavior.
What functions does the calculator support?
Supported: polynomials, logarithmic, trigonometric, exponential functions, and combinations: sin(x), ln(x), x^2, e^x, x*sin(x), sqrt(x), abs(x), fractions, products, etc.
What expression format is supported?
You can use:
  • ^ — exponentiation: x^2
  • sin(x), cos(x), tan(x)
  • ln(x) — natural logarithm (automatically converts to log(x))
  • e^x or exp(x)
  • abs(x) — absolute value
  • sqrt(x) — square root
  • Fractions: x / (x + 1)
How is the derivative of |x| handled?
The derivative of absolute value x is sign(x) or x / |x| (except at point x = 0, where undefined). The calculator shows this as abs(x)/x.
How to copy the derivative?
Simply right-click on the derivative result and select 'Copy text'.

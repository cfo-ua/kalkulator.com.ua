    <h3>🎯 Категорії пенсійного стилю життя</h3>
    
    <p><strong>💎 Розкішний стиль життя:</strong></p>
    <ul>
      <li><strong>100-150% поточного доходу:</strong> Підвищення рівня життя</li>
      <li><strong>Розкоші:</strong> Часті подорожі, преміум-послуги, дорогі хобі</li>
      <li><strong>Житло:</strong> Розкішна нерухомість, декілька об'єктів</li>
      <li><strong>Медицина:</strong> VIP-сервіс, приватні клініки</li>
      <li><strong>Необхідний капітал:</strong> ₴6-12 млн</li>
    </ul>

    <p><strong>🏠 Комфортний стиль життя:</strong></p>
    <ul>
      <li><strong>70-100% поточного доходу:</strong> Підтримання звичного рівня</li>
      <li><strong>Комфорт:</strong> Регулярні подорожі, якісні послуги</li>
      <li><strong>Житло:</strong> Власне житло, можливо заміська нерухомість</li>
      <li><strong>Медицина:</strong> Приватне страхування, якісні послуги</li>
      <li><strong>Необхідний капітал:</strong> ₴3-6 млн</li>
    </ul>

    <p><strong>🌱 Скромний стиль життя:</strong></p>
    <ul>
      <li><strong>50-70% поточного доходу:</strong> Базові потреби плюс дещо більше</li>
      <li><strong>Простота:</strong> Місцеві подорожі, базові послуги</li>
      <li><strong>Житло:</strong> Скромне власне житло</li>
      <li><strong>Медицина:</strong> Державна + базове приватне страхування</li>
      <li><strong>Необхідний капітал:</strong> ₴1.5-3 млн</li>
    </ul>

    <p><strong>🔥 FIRE стиль (фінансова незалежність):</strong></p>
    <ul>
      <li><strong>40-50% поточного доходу:</strong> Мінімалізм та ощадливість</li>
      <li><strong>Свобода:</strong> Дострокова пенсія у 40-50 років</li>
      <li><strong>Пріоритети:</strong> Час важливіше грошей</li>
      <li><strong>Необхідний капітал:</strong> ₴1-2 млн</li>
    </ul>

    <h3>💼 Інструменти накопичення в Україні</h3>
    
    <p><strong>🏦 Консервативні інструменти:</strong></p>
    <ul>
      <li><strong>Банківські депозити:</strong> 10-15% річних, гарантія ФГВФО до 200,000 грн</li>
      <li><strong>ОВДП (облігації):</strong> 14-20% річних, державна гарантія</li>
      <li><strong>Корпоративні облігації:</strong> 15-25% річних, вищий ризик</li>
      <li><strong>Страхування життя:</strong> 8-12% річних + захист</li>
    </ul>

    <p><strong>📊 Помірні інструменти:</strong></p>
    <ul>
      <li><strong>Українські акції:</strong> Потенціал 15-30% річних</li>
      <li><strong>Інвестиційні фонди:</strong> Диверсифікація ризиків</li>
      <li><strong>ETF на іноземних ринках:</strong> Доступ до світових ринків</li>
      <li><strong>Нерухомість:</strong> Оренда + зростання вартості</li>
    </ul>

    <p><strong>⚡ Агресивні інструменти:</strong></p>
    <ul>
      <li><strong>Міжнародні акції:</strong> Через брокерів або ETF</li>
      <li><strong>Стартапи та ІТ:</strong> Високий потенціал росту</li>
      <li><strong>Криптовалюти:</strong> Bitcoin, Ethereum (високий ризик)</li>
      <li><strong>Товарні ринки:</strong> Золото, нафта, аграрії</li>
    </ul>

    <h3>📈 Стратегії інвестування за віком</h3>

    <ul>

      <li>Баланс між ростом та стабільністю</li>
      <li>Диверсифікація ризиків</li>
      <li>Регулярне поповнення портфеля</li>
    </ul>

    <p><strong>👨‍🦳 50+ років (консервативна стратегія):</strong></p>
    <ul>

      <li>Збереження капіталу</li>
      <li>Фокус на стабільний дохід</li>
      <li>Підготовка до виходу на пенсію</li>
    </ul>

    <h3>💡 Практичні поради для накопичення</h3>
    <ul>
      <li><strong>Правило 50/30/20:</strong> 50% на потреби, 30% на бажання, 20% на накопичення</li>
      <li><strong>Автоматизація:</strong> Автоматичні переказі на інвестиційні рахунки</li>
      <li><strong>Податкові пільги:</strong> Використовуйте всі доступні знижки</li>
      <li><strong>Диверсифікація:</strong> Не покладайтеся на один інструмент</li>
      <li><strong>Довгостроковість:</strong> Не панікуйте при короткострокових коливаннях</li>
      <li><strong>Регулярний перегляд:</strong> Щорічна корекція стратегії</li>
    </ul>

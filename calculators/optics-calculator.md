    <h2>🔍 Калькулятор геометричної оптики</h2>
    <p>Геометрична оптика вивчає поширення світла як променів. Цей калькулятор допоможе розрахувати параметри тонких лінз та сферичних дзеркал.</p>
    
    <h3>📐 Основні формули:</h3>
    <ul>
      <li><strong>Формула тонкої лінзи:</strong> 1/f = 1/d₀ + 1/dᵢ</li>
      <li><strong>Лінійне збільшення:</strong> m = -dᵢ/d₀ = hᵢ/h₀</li>
      <li><strong>Оптична сила:</strong> D = 1/f (в діоптріях)</li>
      <li><strong>Зв'язок радіуса та фокуса:</strong> f = R/2 (для дзеркал)</li>
    </ul>
    
    <h3>🔬 Види оптичних елементів:</h3>
    <ul>
      <li><strong>Збираюча лінза:</strong> f > 0 (збирає промені)</li>
      <li><strong>Розсіююча лінза:</strong> f < 0 (розсіює промені)</li>
      <li><strong>Увігнуте дзеркало:</strong> f > 0 (збирає промені)</li>
      <li><strong>Опукле дзеркало:</strong> f < 0 (розсіює промені)</li>
    </ul>

    answer: "Діоптрія - одиниця вимірювання оптичної сили лінзи. 1 діоптрія = 1/метр. Чим більша оптична сила, тим сильніше лінза заломлює світло."

    <h2>Калькулятор сходових тетив</h2>
    <p>Розрахуйте точні <strong>розміри сходових тетив</strong> і планування для будівництва безпечних сходів, що відповідають нормам. Цей професійний калькулятор тетив надає розміри для розрізів, кути та потребу в матеріалах.</p>

    <h3>Основи сходових тетив:</h3>
    <ul>
      <li><strong>Тетиви:</strong> несучі конструкції, що несуть навантаження сходів</li>
      <li><strong>Типовий крок:</strong> 400 мм по центрах, максимум 600 мм</li>
      <li><strong>Матеріал:</strong> дошка 50×300 мм для прольотів до 4 метрів</li>
      <li><strong>Кількість:</strong> 3 тетиви для сходів шириною до 1 метра</li>
    </ul>

    <h3>Вимоги будівельних норм:</h3>
    <ul>
      <li><strong>Висота підсходинки:</strong> 120 мм мінімум, 190 мм максимум</li>
      <li><strong>Глибина проступу:</strong> 250 мм мінімум (житлові)</li>
      <li><strong>Відхилення:</strong> ±10 мм між підсходинками і проступами</li>
      <li><strong>Висота проходу:</strong> 2000 мм мінімум вільної висоти</li>
    </ul>

    <h3>Рекомендовані розміри:</h3>
    <ul>
      <li><strong>Комфортні підсходинки:</strong> 150-170 мм</li>
      <li><strong>Комфортні проступи:</strong> 280-320 мм</li>
      <li><strong>Формула комфорту:</strong> 2h + b = 600-650 мм</li>
      <li><strong>Кут нахилу:</strong> 30-35° оптимально</li>
    </ul>

    <h3>Матеріали та вартість:</h3>
    <ul>
      <li><strong>Тетиви (50×300×4000):</strong> 800-1200 грн за штуку</li>
      <li><strong>Проступи (40 мм товщина):</strong> 1000-1500 грн/м²</li>
      <li><strong>Підсходинки (20 мм):</strong> 600-900 грн/м²</li>
      <li><strong>Крізьплення:</strong> саморізи, кронштейни, клей</li>
    </ul>

    <h3>Інструменти для роботи:</h3>
    <ul>
      <li><strong>Розмітка:</strong> кутник, рівень, рулетка</li>
      <li><strong>Розрізання:</strong> циркулярна пила, лобзик</li>
      <li><strong>З'єднання:</strong> дриль, шуруповерт</li>
      <li><strong>Обробка:</strong> рубанок, шліфмашина</li>
    </ul>

    answer: "Оптимальний кут нахилу для житлових сходів 30-35°. Менше 30° - занадто пологі, більше 40° - занадто круті для комфортного використання."

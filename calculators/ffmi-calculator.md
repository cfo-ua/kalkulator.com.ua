    <h2>💪 Калькулятор FFMI — Оцінка індексу безжирової маси тіла</h2>
    <p>Цей <strong>калькулятор FFMI (Fat-Free Mass Index)</strong> допомагає визначити індекс вашої безжирової маси тіла для оцінки м'язової маси та загальної композиції тіла. FFMI є кращим показником м'язового розвитку, ніж звичайний ІМТ, оскільки враховує лише безжирову масу тіла.</p>

    <h3>🔬 Що таке FFMI?</h3>
    <ul>
      <li><strong>Визначення:</strong> Fat-Free Mass Index — індекс безжирової маси тіла</li>
      <li><strong>Формула:</strong> FFMI = Безжирова маса (кг) / Зріст² (м)</li>
      <li><strong>Мета:</strong> Оцінка м'язової маси незалежно від жирової тканини</li>
      <li><strong>Переваги:</strong> Краще відображає мускулатуру, ніж звичайний ІМТ</li>
      <li><strong>Застосування:</strong> Фітнес, бодібілдинг, спортивна медицина</li>
    </ul>

    <h3>📊 Норми FFMI за статтю</h3>
    
    <h4>Чоловіки</h4>
    <ul>
      <li><strong>Низький (< 16):</strong> Недостатня м'язова маса</li>
      <li><strong>Нормальний (16-18):</strong> Середній рівень м'язової маси</li>
      <li><strong>Добрий (18-20):</strong> Хороша м'язова маса</li>
      <li><strong>Відмінний (20-22):</strong> Відмінна м'язова маса</li>
      <li><strong>Елітний (22-25):</strong> Спортивний/елітний рівень</li>
      <li><strong>Екстремальний (> 25):</strong> Генетична межа або використання ААС</li>
    </ul>

    <h4>Жінки</h4>
    <ul>
      <li><strong>Низький (< 14):</strong> Недостатня м'язова маса</li>
      <li><strong>Нормальний (14-16):</strong> Середній рівень м'язової маси</li>
      <li><strong>Добрий (16-17):</strong> Хороша м'язова маса</li>
      <li><strong>Відмінний (17-18):</strong> Відмінна м'язова маса</li>
      <li><strong>Елітний (18-20):</strong> Спортивний/елітний рівень</li>
      <li><strong>Екстремальний (> 20):</strong> Генетична межа або використання ААС</li>
    </ul>

    <h3>🎯 Фактори, що впливають на FFMI</h3>
    
    <h4>💪 Тренувальні фактори</h4>
    <ul>
      <li><strong>Силові тренування:</strong> Основний чинник збільшення м'язової маси</li>
      <li><strong>Прогресивне навантаження:</strong> Поступове збільшення ваги та інтенсивності</li>
      <li><strong>Частота тренувань:</strong> Регулярність силових вправ</li>
      <li><strong>Об'єм тренувань:</strong> Кількість підходів та вправ</li>
      <li><strong>Відновлення:</strong> Достатній час для росту м'язів</li>
    </ul>

    <h4>🍽️ Харчові фактори</h4>
    <ul>
      <li><strong>Протеїн:</strong> 1.6-2.2 г на кг маси тіла для росту м'язів</li>
      <li><strong>Калорії:</strong> Достатня кількість для анаболічних процесів</li>
      <li><strong>Вуглеводи:</strong> Енергія для інтенсивних тренувань</li>
      <li><strong>Жири:</strong> Гормональний баланс та відновлення</li>
      <li><strong>Вода:</strong> Гідратація для оптимальної роботи м'язів</li>
    </ul>

    <h4>🧬 Генетичні та біологічні фактори</h4>
    <ul>
      <li><strong>Генетичний потенціал:</strong> Природні межі росту м'язів</li>
      <li><strong>Тип тіла:</strong> Ектоморф, мезоморф, ендоморф</li>
      <li><strong>Гормональний статус:</strong> Тестостерон, гормон росту, інсулін</li>
      <li><strong>Вік:</strong> Піковий ріст м'язів у молодому віці</li>
      <li><strong>Стать:</strong> Чоловіки мають більший потенціал м'язової маси</li>
    </ul>

    <h3>📈 Як підвищити FFMI природно</h3>
    
    <h4>🏋️ Оптимальна програма тренувань</h4>
    <ul>
      <li><strong>Силові тренування:</strong> 3-5 разів на тиждень</li>
      <li><strong>Основні вправи:</strong> Присідання, жим, тяга, віджимання</li>
      <li><strong>Діапазон повторень:</strong> 6-12 для гіпертрофії</li>
      <li><strong>Прогресія:</strong> Поступове збільшення навантаження</li>
      <li><strong>Відпочинок:</strong> 48-72 години між тренуваннями групи м'язів</li>
    </ul>

    <h4>🥗 Харчування для росту м'язів</h4>
    <ul>
      <li><strong>Профіцит калорій:</strong> 200-500 калорій понад норму</li>
      <li><strong>Високий протеїн:</strong> М'ясо, риба, яйця, молочні продукти</li>
      <li><strong>Складні вуглеводи:</strong> Рис, вівсянка, картопля</li>
      <li><strong>Здорові жири:</strong> Горіхи, авокадо, оливкова олія</li>
      <li><strong>Режим харчування:</strong> 4-6 прийомів їжі на день</li>
    </ul>

    <h4>😴 Відновлення та спосіб життя</h4>
    <ul>
      <li><strong>Сон:</strong> 7-9 годин якісного сну щоночі</li>
      <li><strong>Управління стресом:</strong> Хронічний стрес заважає росту м'язів</li>
      <li><strong>Гідратація:</strong> 2.5-3.5 літри води на день</li>
      <li><strong>Активне відновлення:</strong> Легкі вправи в дні відпочинку</li>
      <li><strong>Постійність:</strong> Регулярні тренування протягом місяців/років</li>
    </ul>

    <h3>⚡ Реалістичні очікування приросту FFMI</h3>
    <ul>
      <li><strong>Перший рік тренувань:</strong> +2-4 пункти FFMI</li>
      <li><strong>Другий рік:</strong> +1-2 пункти FFMI</li>
      <li><strong>Третій рік і далі:</strong> +0.5-1 пункт FFMI на рік</li>
      <li><strong>Генетична межа:</strong> Зазвичай досягається за 3-5 років</li>
      <li><strong>Природна межа чоловіків:</strong> FFMI 22-25</li>
      <li><strong>Природна межа жінок:</strong> FFMI 18-20</li>
    </ul>

    <h3>🎯 Різниця між FFMI та ІМТ</h3>
    <ul>
      <li><strong>ІМТ:</strong> Враховує загальну масу тіла (м'язи + жир)</li>
      <li><strong>FFMI:</strong> Враховує лише безжирову масу тіла</li>
      <li><strong>Точність:</strong> FFMI краще відображає м'язовий розвиток</li>
      <li><strong>Застосування:</strong> FFMI кращий для спортсменів та фітнес-ентузіастів</li>
      <li><strong>Обмеження:</strong> FFMI потребує знання відсотка жиру в тілі</li>
    </ul>

    <h3>📊 Методи вимірювання відсотка жиру</h3>
    <ul>
      <li><strong>Біоімпеданс:</strong> Доступний, помірна точність</li>
      <li><strong>Калібри (калліпери):</strong> Недорогий, потребує навичок</li>
      <li><strong>DEXA сканування:</strong> Дуже точний, дорогий</li>
      <li><strong>Подводне зважування:</strong> Точний, рідко доступний</li>
      <li><strong>BOD POD:</strong> Точний, дорогий</li>
      <li><strong>МРТ/КТ:</strong> Найточніший, дуже дорогий</li>
    </ul>

    <h3>⚠️ Важливі зауваження щодо FFMI</h3>
    <ul>
      <li><strong>Генетичні обмеження:</strong> Не всі можуть досягти високого FFMI</li>
      <li><strong>Точність вимірювань:</strong> Результат залежить від точності визначення жиру</li>
      <li><strong>Нереалістичні цілі:</strong> FFMI > 25 (чоловіки) або > 20 (жінки) часто нереальні</li>
      <li><strong>Вікові зміни:</strong> З віком FFMI природно знижується</li>
      <li><strong>Здоров'я важливіше:</strong> Не варто жертвувати здоров'ям заради високого FFMI</li>
    </ul>

    <h3>🏆 FFMI елітних атлетів (натуральних)</h3>
    <ul>
      <li><strong>Натуральні бодібілдери (чоловіки):</strong> 20-23</li>
      <li><strong>Натуральні бодібілдери (жінки):</strong> 17-19</li>
      <li><strong>Пауерліфтери:</strong> 22-25+ (часто з вищим відсотком жиру)</li>
      <li><strong>Гімнасти:</strong> 20-22 (чоловіки), 16-18 (жінки)</li>
      <li><strong>Спринтери:</strong> 21-23 (чоловіки), 17-19 (жінки)</li>
    </ul>

    <p><strong>Важливо:</strong> Цей калькулятор FFMI надає оцінки на основі наукових даних та норм для населення. Результати слід інтерпретувати з урахуванням індивідуальних особливостей, цілей та стану здоров'я. Для найточнішої оцінки композиції тіла рекомендується професійне тестування. При плануванні змін у тренуваннях або харчуванні консультуйтеся з кваліфікованими фахівцями.</p>

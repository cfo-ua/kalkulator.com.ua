- answer: Маленькі деталі (50г) коштують $1-5 в матеріалах плюс електрика. Середні деталі (200г) коштують $5-20. Великі деталі (1кг+) можуть коштувати $20-100+. Загальна вартість включаючи роботу та накладні витрати зазвичай в 2-5 разів більше ніж вартість матеріалів для комерційних послуг друку.
  question: Скільки коштує надрукувати типову деталь на 3D принтері?
- answer: FDM зазвичай дешевший за вартістю матеріалів ($20-80/кг проти $50-400/л для смоли), але SLA може бути економічнішим для маленьких, високоточних деталей через швидший друк та менше постобробки.
  question: Що дешевше - FDM чи SLA друк?
- answer: Використовуйте програму слайсера для отримання об'єму в см³, помножте на щільність матеріалу (PLA ~1.24г/см³), додайте 10-20% на підтримки та відходи. Для деталі 100см³, 100 × 1.24 × 1.15 = 143г PLA.
  question: Як розрахувати витрату філаменту для мого друку?
- answer: Підігрівані столи (100-300Вт), підігрів корпусу для високотемпературних матеріалів (200-800Вт) та час друку. Типовий друк PLA використовує 0.1-0.3 кВт⋅год на годину. ABS або PETG з підігрівом корпусу можуть використовувати 0.5-1.0 кВт⋅год на годину.
  question: Які фактори найбільше впливають на вартість електрики для 3D друку?
- answer: Починайте з 3-5x вартості матеріалу для покриття часу, електрики, амортизації обладнання та прибутку. Спеціальні матеріали або складна постобробка можуть виправдовувати 5-10x вартості матеріалу. Досліджуйте місцеві ринкові ціни для порівняння.
  question: Скільки слід брати за послуги 3D друку?
- answer: Для хобійного друку, вартість матеріалів (60-80%). Для професійних послуг час роботи на налаштування, моніторинг та постобробку часто перевищує вартість матеріалів. Амортизація обладнання стає значущою для дорогих промислових принтерів.
  question: Який найбільший фактор витрат у 3D друці?
- answer: Оптимізуйте заповнення (10-20% для більшості деталей), використовуйте дешевші матеріали коли можливо, друкуйте кілька деталей в одному друці, мінімізуйте підтримки через оптимізацію дизайну та вибирайте відповідну висоту шару для балансу якості та швидкості.
  question: Як зменшити витрати на 3D друк?
- answer: Для специфічних застосувань - так. Карбон для легкої міцності, металонаповнені для зовнішнього вигляду, харчові для кухонного приладдя. Однак стандартні PLA/PETG покривають 80% потреб друку за набагато нижчою ціною. Вибирайте базуючись на функціональних вимогах.

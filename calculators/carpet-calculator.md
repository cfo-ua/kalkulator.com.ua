    <h2>Калькулятор килимового покриття</h2>
    <p>Розрахуйте точну кількість <strong>ковроліну та килимового покриття</strong> для ваших кімнат. Калькулятор допоможе визначити площу, кількість рулонів та орієнтовну вартість.</p>

    <h3>🏠 Типи килимових покриттів:</h3>
    <ul>
      <li><strong>Ковролін з петельним ворсом:</strong> довговічний, для офісів</li>
      <li><strong>Ковролін з розрізним ворсом:</strong> м'який, для спалень</li>
      <li><strong>Комбінований ковролін:</strong> універсальний, для вітальень</li>
      <li><strong>Безворсовий ковролін:</strong> легкий в прибиранні</li>
      <li><strong>Модульна плитка:</strong> зручна в укладанні та заміні</li>
    </ul>

    <h3>📏 Стандартні розміри рулонів:</h3>
    <ul>
      <li><strong>Ширина 2 м:</strong> для невеликих кімнат</li>
      <li><strong>Ширина 2,5 м:</strong> найпопулярніший розмір</li>
      <li><strong>Ширина 3 м:</strong> для просторих кімнат</li>
      <li><strong>Ширина 3,5-4 м:</strong> для залів та офісів</li>
      <li><strong>Ширина 5 м:</strong> для великих приміщень</li>
    </ul>

    <h3>🧹 Рекомендації по приміщеннях:</h3>
    <ul>
      <li><strong>Спальні:</strong> м'який ворс 10-15 мм</li>
      <li><strong>Вітальні:</strong> середній ворс 5-10 мм</li>
      <li><strong>Дитячі кімнати:</strong> гіпоалергенний, легко миється</li>
      <li><strong>Офіси:</strong> комерційний ковролін, низький ворс</li>
      <li><strong>Коридори:</strong> високої зносостійкості</li>
    </ul>

    <h3>💡 Поради по вибору:</h3>
    <ul>
      <li><strong>Щільність:</strong> чим вища щільність, тим довговічніший</li>
      <li><strong>Матеріал:</strong> шерсть, нейлон, поліпропілен</li>
      <li><strong>Підкладка:</strong> поліпшує комфорт та теплоізоляцію</li>
      <li><strong>Стійкість кольору:</strong> важливо для сонячних кімнат</li>
    </ul>

    answer: "Так, підкладка покращує комфорт, теплоізоляцію, звукоізоляцію та продовжує термін служби ковроліну."
  - question: Який ковролін вибрати для дитячої кімнати?
    answer: "Для дитячої вибирайте гіпоалергенний ковролін з коротким ворсом, легкий в прибиранні, бажано з натуральних матеріалів."

    <h2>Калькулятор ґрунту для грядок</h2>
    <p>Розрахуйте необхідну кількість <strong>ґрунту для високих грядок</strong> та контейнерного садівництва. Цей калькулятор допоможе оцінити об'єм ґрунтової суміші, компосту та добрив для успішного вирощування.</p>

    <h3>Типи ґрунтових сумішей:</h3>
    <ul>
      <li><strong>Універсальна суміш:</strong> торф + компост + пісок (2:2:1)</li>
      <li><strong>Для овочів:</strong> перегній + садова земля + торф (1:1:1)</li>
      <li><strong>Для трав:</strong> дернова земля + пісок + компост (3:1:1)</li>
      <li><strong>Для квітів:</strong> листова земля + торф + перліт (2:1:1)</li>
      <li><strong>Для розсади:</strong> торф + вермикуліт + компост (2:1:1)</li>
    </ul>

    <h3>Рекомендована глибина для культур:</h3>
    <ul>
      <li><strong>Зелень (салат, шпинат):</strong> 15-20 см</li>
      <li><strong>Редиска, цибуля:</strong> 20-25 см</li>
      <li><strong>Морква, буряк:</strong> 30-35 см</li>
      <li><strong>Капуста, перець:</strong> 35-40 см</li>
      <li><strong>Томати, огірки:</strong> 40-50 см</li>
      <li><strong>Картопля:</strong> 40-60 см</li>
    </ul>

    <h3>Компоненти ґрунтової суміші:</h3>
    <ul>
      <li><strong>Торф:</strong> покращує структуру, утримує вологу</li>
      <li><strong>Компост:</strong> живлення, корисна мікрофлора</li>
      <li><strong>Перегній:</strong> органічні речовини, азот</li>
      <li><strong>Пісок:</strong> дренаж, аерація</li>
      <li><strong>Вермикуліт:</strong> розпушування, утримання вологи</li>
      <li><strong>Кокосове волокно:</strong> екологічна альтернатива торфу</li>
    </ul>

    <h3>Вартість компонентів (за м³):</h3>
    <ul>
      <li><strong>Готова суміш універсальна:</strong> 2000-3000 грн</li>
      <li><strong>Торф нейтралізований:</strong> 1500-2200 грн</li>
      <li><strong>Компост зрілий:</strong> 1200-1800 грн</li>
      <li><strong>Перегній кінський:</strong> 2500-3500 грн</li>
      <li><strong>Біогумус:</strong> 4000-6000 грн</li>
      <li><strong>Пісок річковий:</strong> 800-1200 грн</li>
    </ul>

    <h3>Показники якісного ґрунту:</h3>
    <ul>
      <li><strong>pH:</strong> 6.0-7.0 (нейтральний або слабокислий)</li>
      <li><strong>Вологість:</strong> добре утримує, але не заболочується</li>
      <li><strong>Структура:</strong> розсипчастий, без грудок</li>
      <li><strong>Колір:</strong> темний, багатий органікою</li>
      <li><strong>Запах:</strong> приємний земляний</li>
    </ul>

    <h3>Додаткові компоненти:</h3>
    <ul>
      <li><strong>Вапно:</strong> для зниження кислотності</li>
      <li><strong>Сірка:</strong> для підвищення кислотності</li>
      <li><strong>Перліт:</strong> покращення дренажу</li>
      <li><strong>Деревне вугілля:</strong> абсорбент, профілактика гнилі</li>
    </ul>

    <h3>Сезонність закупівель:</h3>
    <ul>
      <li><strong>Весна (березень-квітень):</strong> пік попиту, високі ціни</li>
      <li><strong>Літо:</strong> стабільні ціни, хороша якість</li>
      <li><strong>Осінь:</strong> знижки, підготовка до наступного сезону</li>
      <li><strong>Зима:</strong> найкращі ціни, обмежена наявність</li>
    </ul>

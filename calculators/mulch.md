    <h2>Калькулятор мульчі</h2>
    <p>Розрахуйте необхідну кількість <strong>мульчуючого матеріалу</strong> для вашого саду та ландшафтного дизайну. Цей калькулятор мульчі допоможе оцінити об'єм деревної тирси, кори, соломи та інших матеріалів.</p>

    <h3>Типи мульчуючих матеріалів:</h3>
    <ul>
      <li><strong>Деревна тирса:</strong> універсальна, покращує ґрунт</li>
      <li><strong>Кора сосни:</strong> декоративна, довговічна</li>
      <li><strong>Солома:</strong> для городів, дешева</li>
      <li><strong>Листя:</strong> безкоштовна, для плодових дерев</li>
      <li><strong>Торф:</strong> підкислює ґрунт</li>
      <li><strong>Кокосове волокно:</strong> екологічна, дренажна</li>
    </ul>

    <h3>Рекомендована товщина мульчі:</h3>
    <ul>
      <li><strong>Квітники та клумби:</strong> 5-7 см</li>
      <li><strong>Навколо дерев:</strong> 7-10 см</li>
      <li><strong>Городні грядки:</strong> 3-5 см</li>
      <li><strong>Доріжки:</strong> 10-15 см</li>
      <li><strong>Ігрові майданчики:</strong> 15-20 см</li>
    </ul>

    <h3>Переваги мульчування:</h3>
    <ul>
      <li><strong>Збереження вологи:</strong> зменшує випаровування на 70%</li>
      <li><strong>Боротьба з бур'янами:</strong> пригнічує ріст</li>
      <li><strong>Захист від морозу:</strong> ізолює коріння</li>
      <li><strong>Покращення ґрунту:</strong> органічна речовина</li>
      <li><strong>Декоративність:</strong> естетичний вигляд</li>
    </ul>

    <h3>Вартість мульчуючих матеріалів (за м³):</h3>
    <ul>
      <li><strong>Деревна тирса:</strong> 800-1200 грн</li>
      <li><strong>Кора сосни подрібнена:</strong> 1500-2500 грн</li>
      <li><strong>Солома в тюках:</strong> 300-500 грн</li>
      <li><strong>Торф'яна крихта:</strong> 1200-1800 грн</li>
      <li><strong>Кокосове волокно:</strong> 3000-4500 грн</li>
      <li><strong>Декоративна кора:</strong> 2000-3500 грн</li>
    </ul>

    <h3>Коли мульчувати:</h3>
    <ul>
      <li><strong>Весна:</strong> після прогрівання ґрунту</li>
      <li><strong>Літо:</strong> для збереження вологи</li>
      <li><strong>Осінь:</strong> підготовка до зими</li>
      <li><strong>Уникати:</strong> мульчування мокрого ґрунту</li>
    </ul>

    <h3>Поради по використанню:</h3>
    <ul>
      <li><strong>Не насипайте впритул до стовбурів</strong> - залиште 10-15 см</li>
      <li><strong>Оновлюйте щорічно</strong> - органічна мульча розкладається</li>
      <li><strong>Перемішуйте з ґрунтом восени</strong> для покращення структури</li>
      <li><strong>Вибирайте за призначенням</strong> - кислі матеріали для хвойних</li>
    </ul>

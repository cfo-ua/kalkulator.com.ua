    <h2>Калькулятор внутрішньої вартості акцій</h2>
    <p>Професійний інструмент для розрахунку <strong>справедливої вартості акцій</strong> за допомогою найпопулярніших методів оцінки. Використовуйте DCF модель, P/E аналіз та дивідендний підхід для прийняття обґрунтованих інвестиційних рішень.</p>

    <h3>Методи оцінки в калькуляторі:</h3>
    <ul>
      <li><strong>DCF модель (Discounted Cash Flow)</strong> - базується на дисконтуванні майбутніх грошових потоків</li>
      <li><strong>P/E аналіз</strong> - оцінка на основі коефіцієнта ціна/прибуток</li>
      <li><strong>Дивідендна модель Гордона</strong> - для компаній з стабільними дивідендами</li>
      <li><strong>Балансова вартість</strong> - оцінка на основі чистих активів</li>
    </ul>

    <h3>Основні переваги:</h3>
    <ul>
      <li>🎯 <strong>Точність розрахунків</strong> - використання перевірених фінансових моделей</li>
      <li>📊 <strong>Кілька методів оцінки</strong> - для порівняння та підтвердження результатів</li>
      <li>⚡ <strong>Швидкий аналіз</strong> - миттєві результати з детальним поясненням</li>
      <li>💡 <strong>Інвестиційні рекомендації</strong> - висновки про доцільність покупки</li>
    </ul>

    <h3>Для кого цей інструмент:</h3>
    <ul>
      <li><strong>Приватні інвестори</strong> - для аналізу потенційних інвестицій</li>
      <li><strong>Фінансові аналітики</strong> - для професійної оцінки компаній</li>
      <li><strong>Портфельні менеджери</strong> - для скринінгу та відбору активів</li>
      <li><strong>Студенти фінансів</strong> - для вивчення методів оцінки</li>
    </ul>

faq:
  - question: "Що таке внутрішня вартість акції?"
    answer: "Внутрішня вартість - це справедлива ціна акції, розрахована на основі фундаментальних показників компанії, таких як прибутки, грошові потоки, активи та перспективи зростання. Вона може відрізнятися від ринкової ціни."

  - question: "Який метод оцінки найточніший?"
    answer: "Немає універсально найточнішого методу. DCF модель краща для зростаючих компаній, P/E аналіз - для зрілих бізнесів, дивідендна модель - для компаній з стабільними виплатами. Рекомендується використовувати кілька методів одночасно."

  - question: "Як часто потрібно переоцінювати акції?"
    answer: "Рекомендується переоцінювати портфель щокварталу або при значних змінах у фундаментальних показниках компанії. Також варто проводити оцінку перед прийняттям інвестиційних рішень."

  - question: "Чи враховує калькулятор інфляцію?"
    answer: "Так, DCF модель враховує інфляцію через ставку дисконтування. Рекомендується використовувати реальну (очищену від інфляції) ставку дисконтування для більш точних результатів."

  - question: "Що робити, якщо внутрішня вартість значно відрізняється від ринкової ціни?"
    answer: "Велика різниця може вказувати на неточність в оцінці або на ринкову неефективність. Перевірте вхідні дані, розгляньте додаткові фактори та проконсультуйтеся з фінансовим консультантом перед прийняттям рішень."

    <h2>Калькулятор доступної іпотеки — визначте вашу спроможність</h2>
    <p>Дізнайтеся <strong>максимальну суму іпотечного кредиту</strong>, яку ви можете отримати на основі вашого доходу, наявних боргів та фінансових зобов'язань. Плануйте покупку житла відповідно до ваших реальних можливостей.</p>

    <h3>Що враховується при розрахунку:</h3>
    <ul>
      <li><strong>Місячний дохід:</strong> Офіційна зарплата, бонуси, додаткові доходи</li>
      <li><strong>Наявні борги:</strong> Кредити, кредитні картки, аліменти</li>
      <li><strong>Щомісячні витрати:</strong> Комунальні, харчування, транспорт</li>
      <li><strong>Процентна ставка:</strong> Поточні ставки по іпотеці</li>
      <li><strong>Термін кредиту:</strong> Бажаний період погашення</li>
      <li><strong>Первинний внесок:</strong> Доступна сума для початкового платежу</li>
    </ul>

    <h3>Критерії українських банків:</h3>
    <ul>
      <li><strong>Співвідношення DTI:</strong> Платіж по кредиту не більше 40-50% доходу</li>
      <li><strong>Мінімальний стаж:</strong> 6-12 місяців на поточному місці роботи</li>
      <li><strong>Вік позичальника:</strong> 21-65 років на момент закінчення кредиту</li>
      <li><strong>Кредитна історія:</strong> Відсутність простроченої заборгованості</li>
      <li><strong>Первинний внесок:</strong> Мінімум 10-30% від вартості житла</li>
    </ul>

    <h3>Типи доходів, що враховуються:</h3>
    <ul>
      <li><strong>Основна зарплата:</strong> Офіційний дохід за трудовим договором</li>
      <li><strong>Премії та бонуси:</strong> Регулярні додаткові виплати (70-80% від суми)</li>
      <li><strong>Підприємницький дохід:</strong> ФОП з документальним підтвердженням</li>
      <li><strong>Пенсія:</strong> Державна або недержавна пенсія</li>
      <li><strong>Дохід від оренди:</strong> Підтверджений договорами оренди</li>
      <li><strong>Інвестиційний дохід:</strong> Дивіденди, депозитні проценти</li>
    </ul>

    <h3>Фактори, що впливають на суму кредиту:</h3>
    <p><strong>Позитивні фактори:</strong></p>
    <ul>
      <li>Високий стабільний дохід</li>
      <li>Хороша кредитна історія</li>
      <li>Великий первинний внесок</li>
      <li>Працевлаштування в надійній компанії</li>
      <li>Додаткове забезпечення</li>
    </ul>

    <p><strong>Негативні фактори:</strong></p>
    <ul>
      <li>Нестабільні доходи</li>
      <li>Наявність інших кредитів</li>
      <li>Низький кредитний рейтинг</li>
      <li>Високі щомісячні витрати</li>
      <li>Короткий трудовий стаж</li>
    </ul>

    <h3>Рекомендації для збільшення кредитної спроможності:</h3>
    <ul>
      <li><strong>Погасіть існуючі борги:</strong> Зменшіть загальне навантаження</li>
      <li><strong>Накопичте більший первинний внесок:</strong> 30%+ покращують умови</li>
      <li><strong>Покращіть кредитну історію:</strong> Своєчасно платіть по всіх зобов'язаннях</li>
      <li><strong>Збільшіть термін кредиту:</strong> Менші платежі = більша доступна сума</li>
      <li><strong>Залучіть співпозичальника:</strong> Подружжя або близькі родичі</li>
      <li><strong>Розгляньте державні програми:</strong> Пільгові умови кредитування</li>
    </ul>

    <h3>Державні програми доступного житла:</h3>
    <ul>
      <li><strong>"Доступне житло":</strong> 7% річних для молодих сімей</li>
      <li><strong>Програма для АТОвців:</strong> Пільгові умови для учасників бойових дій</li>
      <li><strong>Молодіжні програми:</strong> Спеціальні умови для громадян до 35 років</li>
      <li><strong>Енергоефективне житло:</strong> Знижені ставки для енергоефективних будинків</li>
    </ul>

    <h3>Приблизні ціни на житло в Україні (2024):</h3>
    <ul>
      <li><strong>Київ:</strong> 45,000-80,000 грн/м² (новобудови)</li>
      <li><strong>Харків:</strong> 25,000-40,000 грн/м²</li>
      <li><strong>Дніпро:</strong> 22,000-35,000 грн/м²</li>
      <li><strong>Одеса:</strong> 30,000-50,000 грн/м²</li>
      <li><strong>Львів:</strong> 28,000-45,000 грн/м²</li>
      <li><strong>Обласні центри:</strong> 15,000-25,000 грн/м²</li>
    </ul>

  - question: "Чи враховуються доходи дружини/чоловіка?"
    answer: "Так, банки враховують доходи всіх співпозичальників. Подружжя може подавати спільну заявку, що збільшує загальну кредитоспроможність."
  - question: "Як впливає наявність дітей на розрахунок?"
    answer: "Діти збільшують щомісячні витрати сім'ї, що може зменшити доступну суму кредиту. Однак деякі програми надають пільги багатодітним сім'ям."
  - question: "Чи можна враховувати неофіційні доходи?"
    answer: "Банки враховують тільки документально підтверджені доходи. Неофіційні доходи не беруться до уваги при розрахунку кредитоспроможності."
  - question: "Що робити, якщо доходу недостатньо?"
    answer: "Можна залучити співпозичальника, збільшити первинний внесок, розглянути довший термін кредиту або розглянути дешевше житло."
  - question: "Як довго діє рішення банку про попереднє схвалення?"
    answer: "Зазвичай 30-90 днів, залежно від банку. За цей час потрібно знайти житло та оформити всі документи для остаточного схвалення кредиту."

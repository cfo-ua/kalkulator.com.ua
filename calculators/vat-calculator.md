    <h2>Калькулятор ПДВ</h2>
    <p>Введіть будь-які <strong>два значення</strong> — калькулятор автоматично визначить третє. Ви можете розрахувати:</p>
    <ul>
      <li>Ціну <strong>з ПДВ</strong>, знаючи ставку та ціну без ПДВ</li>
      <li>Ціну <strong>без ПДВ</strong>, знаючи ставку та ціну з ПДВ</li>
      <li><strong>Ставку ПДВ</strong>, якщо відомі обидві ціни</li>
    </ul>
    <h3>Як користуватися калькулятором ПДВ</h3>
    <ol>
      <li>Вкажіть ставку ПДВ (наприклад, 20%, 7% або 0%)</li>
      <li>Введіть відому суму — з ПДВ або без ПДВ</li>
      <li>Калькулятор миттєво обчислить третє значення</li>
    </ol>
    <h3>Формули розрахунку ПДВ</h3>
    <ul>
      <li><strong>Ціна з ПДВ =</strong> Ціна без ПДВ × (1 + ставка / 100)</li>
      <li><strong>Ціна без ПДВ =</strong> Ціна з ПДВ / (1 + ставка / 100)</li>
      <li><strong>Сума ПДВ =</strong> Ціна з ПДВ - Ціна без ПДВ</li>
    </ul>
    <h3>Що таке ПДВ?</h3>
    <p><strong>ПДВ (податок на додану вартість)</strong> — це непрямий податок, який нараховується на товари та послуги на кожному етапі постачання. В Україні основна ставка ПДВ становить 20%, але також існують знижені ставки: <strong>7%</strong> (наприклад, на ліки), <strong>0%</strong> (на експорт).</p>
    <h3>Приклади розрахунку ПДВ</h3>
    <ul>
      <li><strong>Нарахування ПДВ:</strong> якщо сума без ПДВ 1000 грн, ставка 20% ⇒ ціна з ПДВ = 1000 × 1.2 = 1200 грн</li>
      <li><strong>Виділення ПДВ:</strong> якщо ціна з ПДВ 1200 грн, ставка 20% ⇒ ціна без ПДВ = 1200 / 1.2 = 1000 грн, ПДВ = 200 грн</li>
      <li><strong>Зворотній розрахунок:</strong> якщо знаєте обидві ціни, ставка = ((Ціна з ПДВ / Ціна без ПДВ) - 1) × 100%</li>
    </ul>
    <h3>Навіщо використовувати онлайн калькулятор ПДВ?</h3>
    <p>Цей інструмент зручний для бухгалтерів, підприємців, ФОПів, покупців і продавців. Він дозволяє швидко та точно:</p>
    <ul>
      <li>розділити суму на ПДВ і базову частину</li>
      <li>перевірити правильність нарахування податку</li>
      <li>скористатись ставками 7%, 20%, 0%</li>
      <li>застосовувати до будь-якої сфери: покупки, послуги, торгівля, імпорт/експорт</li>
    </ul>
    <h3>Калькулятор ПДВ з розшифровкою суми</h3>
    <p>Після розрахунку ви побачите повну розшифровку: сума без ПДВ, сума ПДВ, загальна вартість. Це дозволяє краще контролювати витрати та формувати звітність.</p>

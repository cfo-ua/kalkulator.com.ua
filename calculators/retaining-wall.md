    <h2>Калькулятор підпірних стін</h2>
    <p>Розрахуйте точні матеріали для вашого <strong>будівництва підпірної стіни</strong>. Цей професійний калькулятор оцінює блоки, основний щебінь, засипку, дренаж і вартість для ландшафтних підпірних стін.</p>

    <h3>Рекомендації по висоті підпірних стін:</h3>
    <ul>
      <li><strong>До 1 метра:</strong> прості гравітаційні стіни, можна робити самостійно</li>
      <li><strong>1-1,2 метра:</strong> може потребувати проектування, дозволів</li>
      <li><strong>1,2-1,8 метра:</strong> потребує професійного проектування</li>
      <li><strong>Понад 1,8 метра:</strong> складне проектування, спеціальні дозволи</li>
    </ul>

    <h3>Популярні типи і розміри блоків:</h3>
    <ul>
      <li><strong>Стандартні блоки:</strong> 400×200×200 мм</li>
      <li><strong>Великі блоки:</strong> 500×250×250 мм</li>
      <li><strong>Кришкові блоки:</strong> 400×100×200 мм (верхній ряд)</li>
      <li><strong>Кутові блоки:</strong> спеціальні форми для поворотів 90°</li>
      <li><strong>Природний камінь:</strong> різний, зазвичай 150-300 мм висота</li>
    </ul>

    <h3>Конструктивні елементи:</h3>
    <ul>
      <li><strong>Фундаментна підошва:</strong> щебеневе підґрунтя 150-300 мм</li>
      <li><strong>Дренажна засипка:</strong> щебінь за стіною</li>
      <li><strong>Геосітка:</strong> армування для високих стін</li>
      <li><strong>Дренажні труби:</strong> відвід води з-за стіни</li>
    </ul>

    <h3>Вартість матеріалів (орієнтовна):</h3>
    <ul>
      <li><strong>Бетонні блоки стандартні:</strong> 85-120 грн/шт</li>
      <li><strong>Декоративні блоки:</strong> 150-250 грн/шт</li>
      <li><strong>Природний камінь:</strong> 800-1500 грн/м²</li>
      <li><strong>Щебінь фракції 5-20:</strong> 1000-1500 грн/м³</li>
      <li><strong>Геосітка:</strong> 120-200 грн/м²</li>
      <li><strong>Дренажні труби:</strong> 50-80 грн/м</li>
    </ul>

    <h3>Типи підпірних стін:</h3>
    <ul>
      <li><strong>Гравітаційні:</strong> утримуються власною вагою</li>
      <li><strong>Консольні:</strong> з армуванням та фундаментом</li>
      <li><strong>Сегментні:</strong> з блоків з системою замків</li>
      <li><strong>Габіонові:</strong> з металевих кошиків з каменем</li>
    </ul>

    <h3>Вимоги до дренажу:</h3>
    <ul>
      <li><strong>Дренажна засипка:</strong> щебінь 300-500 мм за стіною</li>
      <li><strong>Дренажні труби:</strong> кожні 3-4 метри довжини</li>
      <li><strong>Геотекстиль:</strong> фільтрація між ґрунтом і щебнем</li>
      <li><strong>Водовідвідні отвори:</strong> в нижніх рядах блоків</li>
    </ul>

    <h3>Поради по будівництву:</h3>
    <ul>
      <li><strong>Фундамент:</strong> нижче рівня промерзання</li>
      <li><strong>Нахил назад:</strong> 1-2° для стабільності</li>
      <li><strong>Перев'язка швів:</strong> зміщення блоків у рядах</li>
      <li><strong>Ущільнення:</strong> кожен шар засипки</li>
    </ul>

    <h2>Калькулятор зарплати брутто-нетто — розрахунок чистої зарплати</h2>
    <p>Розрахуйте <strong>чисту зарплату (нетто)</strong> з брутто зарплати або визначте необхідну брутто зарплату для отримання бажаної суми на руки. Калькулятор враховує всі податки та збори згідно з українським законодавством.</p>

    <h3>Що включає розрахунок зарплати в Україні:</h3>
    <ul>
      <li><strong>ПДФО:</strong> 18% для резидентів (20% для нерезидентів)</li>
      <li><strong>Військовий збір:</strong> 1.5% з усіх доходів</li>
      <li><strong>ЄСВ працівника:</strong> 3% від зарплати</li>
      <li><strong>ЄСВ роботодавця:</strong> 22% (додаткові витрати роботодавця)</li>
      <li><strong>Податкова соціальна пільга:</strong> Зменшує базу оподаткування</li>
    </ul>

    <h3>Формула розрахунку чистої зарплати:</h3>
    <ol>
      <li><strong>Нарахована зарплата (брутто)</strong> — початкова сума</li>
      <li><strong>База для ПДФО</strong> = Брутто — Податкова соціальна пільга</li>
      <li><strong>ПДФО</strong> = База для ПДФО × 18%</li>
      <li><strong>Військовий збір</strong> = Брутто × 1.5%</li>
      <li><strong>ЄСВ працівника</strong> = Брутто × 3%</li>
      <li><strong>Чиста зарплата (нетто)</strong> = Брутто - ПДФО - Військовий збір - ЄСВ</li>
    </ol>

    <h3>Податкова соціальна пільга (2024):</h3>
    <ul>
      <li><strong>Розмір пільги:</strong> 1,379 грн/місяць (50% прожиткового мінімуму)</li>
      <li><strong>Право на пільгу:</strong> Зарплата до 4,137 грн/місяць</li>
      <li><strong>Поступове зменшення:</strong> При зарплаті 4,137-8,274 грн</li>
      <li><strong>Відсутність пільги:</strong> При зарплаті понад 8,274 грн</li>
    </ul>

    <h3>Мінімальні розміри оплати праці (2024):</h3>
    <ul>
      <li><strong>Мінімальна зарплата:</strong> 7,100 грн/місяць</li>
      <li><strong>Мінімальна погодинна:</strong> 42.29 грн/годину</li>
      <li><strong>Прожитковий мінімум:</strong> 2,759 грн/місяць</li>
      <li><strong>Максимальна база ЄСВ:</strong> 177,500 грн/місяць</li>
    </ul>

    <h3>Особливості оподаткування:</h3>
    <p><strong>Зарплата найманих працівників:</strong></p>
    <ul>
      <li>ПДФО — 18% з бази після ПСП</li>
      <li>Військовий збір — 1.5% з повної суми</li>
      <li>ЄСВ працівника — 3% з зарплати</li>
      <li>ЄСВ роботодавця — 22% (не входить в зарплату)</li>
    </ul>

    <p><strong>Пільги та звільнення:</strong></p>
    <ul>
      <li><strong>Учасники АТО/ООС:</strong> Повне звільнення від ПДФО та військового збору</li>
      <li><strong>Особи з інвалідністю:</strong> Пільги залежно від групи</li>
      <li><strong>Матеріальна допомога:</strong> До 9,175 грн на рік</li>
      <li><strong>Подарунки від роботодавця:</strong> До 9,175 грн на рік</li>
    </ul>

    <h3>Витрати роботодавця:</h3>
    <ul>
      <li><strong>Нарахована зарплата:</strong> Основна сума</li>
      <li><strong>ЄСВ роботодавця:</strong> 22% від зарплати</li>
      <li><strong>Загальні витрати:</strong> Зарплата + 22% ЄСВ</li>
      <li><strong>Приклад:</strong> При зарплаті 20,000 грн витрати становлять 24,400 грн</li>
    </ul>

    <h3>Корисні співвідношення:</h3>
    <ul>
      <li><strong>Ефективна ставка:</strong> ~22.5% від брутто зарплати (для зарплат понад ПСП)</li>
      <li><strong>Чиста зарплата:</strong> ~77.5% від брутто (приблизно)</li>
      <li><strong>Витрати роботодавця:</strong> 122% від брутто зарплати працівника</li>
      <li><strong>Чиста від витрат роботодавця:</strong> ~63.5% того, що витрачає роботодавець</li>
    </ul>

    <h3>Приклади розрахунків:</h3>
    <p><strong>Зарплата 25,000 грн (без ПСП):</strong></p>
    <ul>
      <li>ПДФО: 25,000 × 18% = 4,500 грн</li>
      <li>Військовий збір: 25,000 × 1.5% = 375 грн</li>
      <li>ЄСВ: 25,000 × 3% = 750 грн</li>
      <li>Чиста зарплата: 25,000 - 4,500 - 375 - 750 = 19,375 грн</li>
      <li>Витрати роботодавця: 25,000 + 5,500 = 30,500 грн</li>
    </ul>

    <p>Використовуйте цей калькулятор для точного розрахунку зарплати при прийомі на роботу, плануванні бюджету або HR-розрахунках.</p>

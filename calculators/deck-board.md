    <h2>Калькулятор дошок для терас - Скільки дощок потрібно?</h2>
    <p>Розрахуйте точно <strong>скільки терасних дощок вам потрібно</strong> та оцініть загальну вартість терас. Цей комплексний калькулятор терас допоможе спланувати проект з точними розрахунками матеріалів для композитного настилу, імпрегнованої деревини, кедра та всіх компонентів терас.</p>

    <h3>🏗️ Як користуватися калькулятором терас:</h3>
    <ol>
      <li><strong>Введіть розміри терас:</strong> довжину та ширину вашої терас</li>
      <li><strong>Оберіть розмір дощок:</strong> 32×140, 40×140 або композитні планки</li>
      <li><strong>Виберіть тип матеріалу:</strong> імпрегнована деревина, кедр або композит</li>
      <li><strong>Отримайте результат:</strong> кількість дощок, вартість та повний список матеріалів</li>
    </ol>

    <h3>📐 Стандартні розміри терасних дощок і відстані:</h3>
    <ul>
      <li><strong>32×140 мм терасні дошки:</strong> найпопулярніші для житлових терас</li>
      <li><strong>40×140 мм терасні дошки:</strong> товщі, міцніший варіант</li>
      <li><strong>Композитні дошки:</strong> 25×140 мм або 32×140 мм типові розміри</li>
      <li><strong>Відстань між дошками:</strong> рекомендовано 5-8 мм для дренажу</li>
    </ul>

    <h3>💰 Калькулятор вартості терас - Прайс на матеріали:</h3>
    <ul>
      <li><strong>Імпрегнована сосна:</strong> 800-1200 грн/м² | Економний варіант, термін служби 15-20 років</li>
      <li><strong>Лиственниця:</strong> 1500-2200 грн/м² | Природна краса, термін служби 15-25 років</li>
      <li><strong>Композитний настил:</strong> 1800-3500 грн/м² | Мінімальне обслуговування, 25+ років</li>
      <li><strong>Преміум композит:</strong> 2500-4500 грн/м² | Найвища якість, гарантія 30+ років</li>
    </ul>

    <h3>🔨 Повний список матеріалів для терас:</h3>
    <ul>
      <li><strong>Терасні дошки:</strong> розраховується на основі ваших розмірів</li>
      <li><strong>Лаги:</strong> 50×150 мм або 50×200 мм залежно від прольоту</li>
      <li><strong>Крок лаг:</strong> 400 мм, 500 мм або 600 мм (композит потребує максимум 400 мм)</li>
      <li><strong>Кріплення:</strong> терасні саморізи, лагові гвинти, анкери для стовпів</li>
    </ul>

    <h3>🏠 Композитний настил - особливості калькулятора:</h3>
    <ul>
      <li><strong>Композит з покриттям:</strong> преміум варіант із захисною оболонкою</li>
      <li><strong>Композит без покриття:</strong> економний композитний варіант</li>
      <li><strong>Приховані кріплення:</strong> створюють чисту поверхню без саморізів</li>
      <li><strong>Рифлена vs гладка:</strong> різні текстури та протиковзання</li>
    </ul>

    <h3>📏 Скільки дощок потрібно для терас? - Швидкий довідник:</h3>
    <ul>
      <li><strong>Мала тераса (10 м²):</strong> ~25-28 дощок (32×140 мм × 4 м)</li>
      <li><strong>Середня тераса (20 м²):</strong> ~50-55 дощок (32×140 мм × 4 м)</li>
      <li><strong>Велика тераса (30 м²):</strong> ~75-80 дощок (32×140 мм × 4 м)</li>
      <li><strong>Додайте 10% запасу:</strong> на підрізку, браковані дошки та майбутній ремонт</li>
    </ul>

    <h3>🇺🇦 Українські особливості будівництва терас:</h3>
    <ul>
      <li><strong>Будівельні норми:</strong> висота, перила, вимоги дозвільних служб</li>
      <li><strong>Кліматичні умови:</strong> матеріали стійкі до циклів заморозку-відтавання</li>
      <li><strong>Місцеві постачальники:</strong> ціни можуть відрізнятися по регіонах</li>
      <li><strong>Сезонність:</strong> краще будувати з квітня по жовтень</li>
    </ul>

    <h3>⚡ Додаткові витрати - розрахунок вартості:</h3>
    <ul>
      <li><strong>Робота:</strong> 300-800 грн/м² (залежить від регіону та складності)</li>
      <li><strong>Дозволи:</strong> 500-3000 грн залежно від місцевих вимог</li>
      <li><strong>Оренда інструменту:</strong> 500-2000 грн якщо не маєте власного</li>
      <li><strong>Доставка:</strong> 500-3000 грн залежно від кількості матеріалу</li>
    </ul>

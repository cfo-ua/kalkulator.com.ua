    <h2>Калькулятор дошок для терас</h2>
    <p>Розрахуйте всі <strong>матеріали, необхідні</strong> для вашого проекту будівництва терас. Цей комплексний калькулятор терас оцінює терасні дошки, лаги, балки, стовпи, кріплення та вартість для імпрегнованої деревини, кедра та композитного настилу.</p>

    <h3>Як користуватися калькулятором терас:</h3>
    <ol>
      <li><strong>Введіть розміри терас:</strong> довжину та ширину вашої терас</li>
      <li><strong>Оберіть розмір дошок:</strong> 32×140, 40×140 або композитні планки</li>
      <li><strong>Виберіть крок лаг:</strong> 400, 500 або 600 мм по центрах</li>
      <li><strong>Оберіть матеріали:</strong> імпрегнована деревина, кедр або композит</li>
    </ol>

    <h3>Стандартні розміри терасних дошок:</h3>
    <ul>
      <li><strong>32×140 мм терасні дошки:</strong> найпоширеніші для житлових терас</li>
      <li><strong>40×140 мм терасні дошки:</strong> товщі, міцніший варіант</li>
      <li><strong>Композитні дошки:</strong> 25×140 мм або 32×140 мм типові</li>
      <li><strong>Кедрові дошки:</strong> 32×140 мм або 40×140 мм доступні</li>
    </ul>

    <h3>Вимоги до лаг і каркасу:</h3>
    <ul>
      <li><strong>Лаги:</strong> 50×150 мм або 50×200 мм залежно від прольоту</li>
      <li><strong>Крок лаг:</strong> 400 мм для 32 мм дощок, 500 мм для 40 мм</li>
      <li><strong>Балки:</strong> 100×200 мм або більше для основних прольотів</li>
      <li><strong>Стовпи:</strong> 100×100 мм мінімум для підтримки</li>
    </ul>

    <h3>Ціни на матеріали для терас (за м²):</h3>
    <ul>
      <li><strong>Імпрегнована сосна:</strong> 800-1200 грн/м²</li>
      <li><strong>Лиственниця:</strong> 1500-2200 грн/м²</li>
      <li><strong>Кедр:</strong> 2000-3000 грн/м²</li>
      <li><strong>Дуб:</strong> 2500-4000 грн/м²</li>
      <li><strong>Композитний настил:</strong> 1800-3500 грн/м²</li>
      <li><strong>ДПК (деревно-полімерний композит):</strong> 1200-2500 грн/м²</li>
    </ul>

    <h3>Переваги різних матеріалів:</h3>
    <ul>
      <li><strong>Імпрегнована деревина:</strong> доступна, легка в обробці</li>
      <li><strong>Лиственниця:</strong> природна стійкість до вологи</li>
      <li><strong>Композит:</strong> не потребує обслуговування, довговічний</li>
      <li><strong>Кедр:</strong> природні захисні властивості, красивий</li>
    </ul>

    <h3>Кріплення та аксесуари:</h3>
    <ul>
      <li><strong>Саморізи:</strong> нержавіючі або оцинковані</li>
      <li><strong>Скрытые кліпси:</strong> для композитних дощок</li>
      <li><strong>Анкери:</strong> для кріплення до фундаменту</li>
      <li><strong>Гвинти лагові:</strong> для з'єднання каркасу</li>
    </ul>

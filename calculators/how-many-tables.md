    <h2>Калькулятор кількості столів для заходу</h2>
    <p>Плануєте весілля, корпоративний захід чи святкування? Наш калькулятор допоможе визначити оптимальну кількість столів для комфортного розміщення всіх гостей.</p>

    <h3>Як користуватися калькулятором:</h3>
    <ol>
      <li>Введіть загальну кількість гостей</li>
      <li>Оберіть тип столів (круглі або прямокутні)</li>
      <li>Вкажіть розмір столів</li>
      <li>Натисніть "Розрахувати"</li>
    </ol>

    <h3>Рекомендації по розміщенню:</h3>
    <ul>
      <li><strong>Круглі столи:</strong> створюють більш інтимну атмосферу, легше спілкуватися</li>
      <li><strong>Прямокутні столи:</strong> економлять простір, підходять для офіційних заходів</li>
      <li><strong>Комфортна відстань:</strong> 60-70 см на одну особу</li>
      <li><strong>Додатковий простір:</strong> враховуйте проходи між столами</li>
    </ul>

    <h3>Типи заходів і особливості:</h3>
    <p><strong>Весілля:</strong> зазвичай використовують круглі столи на 8-10 осіб для створення затишної атмосфери.</p>
    <p><strong>Корпоративи:</strong> прямокутні столи на 6-8 осіб зручніші для презентацій та спілкування.</p>
    <p><strong>Дні народження:</strong> залежить від віку і формату святкування.</p>

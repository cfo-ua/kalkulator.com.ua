    <h2>Калькулятор тротуарної плитки</h2>
    <p>Розрахуйте точну кількість <strong>тротуарної плитки</strong> для вашого патіо, доріжки або під'їзду. Цей професійний калькулятор бруківки оцінює плитку, основні матеріали, пісок і вартість укладання.</p>

    <h3>Як розрахувати потребу в плитці:</h3>
    <ol>
      <li><strong>Виміряйте площу:</strong> довжина × ширина зони мощення</li>
      <li><strong>Оберіть розмір плитки:</strong> популярні розміри та візерунки</li>
      <li><strong>Додайте запас:</strong> 5-10% на обрізки та бій</li>
      <li><strong>Розрахуйте основні матеріали:</strong> шари щебеню та піску</li>
    </ol>

    <h3>Популярні розміри плитки та покриття:</h3>
    <ul>
      <li><strong>100×200 мм цеглинка:</strong> 50 шт/м²</li>
      <li><strong>200×200 мм квадрат:</strong> 25 шт/м²</li>
      <li><strong>300×300 мм великий квадрат:</strong> 11 шт/м²</li>
      <li><strong>400×400 мм плита:</strong> 6,25 шт/м²</li>
      <li><strong>500×500 мм велика плита:</strong> 4 шт/м²</li>
      <li><strong>Фігурна "Хвиля":</strong> 40-45 шт/м²</li>
    </ul>

    <h3>Шари основи під плитку:</h3>
    <ul>
      <li><strong>Піщана подушка:</strong> 30-50 мм товщина</li>
      <li><strong>Щебеневе підґрунтя:</strong> 100-150 мм товщина</li>
      <li><strong>Геотекстиль:</strong> між шарами для стабільності</li>
      <li><strong>Бордюр:</strong> для утримання країв</li>
    </ul>

    <h3>Вартість матеріалів (орієнтовна):</h3>
    <ul>
      <li><strong>Бетонна плитка:</strong> 250-450 грн/м²</li>
      <li><strong>Клінкерна цегла:</strong> 800-1500 грн/м²</li>
      <li><strong>Гранітна бруківка:</strong> 1200-2500 грн/м²</li>
      <li><strong>Пісок для укладання:</strong> 800-1200 грн/м³</li>
      <li><strong>Щебінь фракції 5-20:</strong> 1000-1500 грн/м³</li>
      <li><strong>Геотекстиль:</strong> 35-60 грн/м²</li>
    </ul>

    <h3>Типи тротуарної плитки:</h3>
    <ul>
      <li><strong>Вібропресована:</strong> економична, для доріжок</li>
      <li><strong>Вібролита:</strong> декоративна, різні кольори</li>
      <li><strong>Клінкерна:</strong> преміум, морозостійка</li>
      <li><strong>Гранітна:</strong> найдовговічніша, для навантажень</li>
    </ul>

    <h3>Схеми укладання:</h3>
    <ul>
      <li><strong>"Цеглинка":</strong> зміщення на половину довжини</li>
      <li><strong>"Ялинка":</strong> під кутом 45° або 90°</li>
      <li><strong>"Плетінка":</strong> поперемінні напрямки</li>
      <li><strong>"Випадкова":</strong> хаотичне розміщення</li>
    </ul>

    <h3>Поради щодо укладання:</h3>
    <ul>
      <li><strong>Підготовка основи:</strong> найважливіший етап</li>
      <li><strong>Дренаж:</strong> передбачте відвід води</li>
      <li><strong>Ущільнення:</strong> кожен шар ретельно утрамбуйте</li>
      <li><strong>Заповнення швів:</strong> пісок або спеціальні суміші</li>
    </ul>

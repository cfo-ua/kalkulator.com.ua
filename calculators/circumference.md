    <h2>Калькулятор довжини кола онлайн</h2>
    <p>Довжина кола (окружності) — це відстань навколо краю круга. Обчислюється за формулами: <strong>C = 2πr</strong> або <strong>C = πd</strong>, де π ≈ 3.14159.</p>

    <h3>Як користуватись калькулятором?</h3>
    <p>Введіть радіус або діаметр кола і натисніть «Обчислити». Калькулятор автоматично обчислить:</p>
    <ul>
      <li>Довжину окружності</li>
      <li>Площу круга</li>
      <li>Радіус (якщо введено діаметр)</li>
      <li>Діаметр (якщо введено радіус)</li>
    </ul>

    <h3>Основні поняття:</h3>
    <ul>
      <li><strong>Радіус (r)</strong> — відстань від центру до краю кола</li>
      <li><strong>Діаметр (d)</strong> — найбільша відстань через центр кола (d = 2r)</li>
      <li><strong>Довжина кола (C)</strong> — периметр круга</li>
      <li><strong>Число π (пі)</strong> — математична константа ≈ 3.14159</li>
    </ul>

    <h3>Формули для кола:</h3>
    <ul>
      <li><strong>C = 2πr</strong> — довжина через радіус</li>

      <li><strong>A = πr²</strong> — площа круга</li>
      <li><strong>d = 2r</strong> — зв'язок діаметра і радіуса</li>
    </ul>

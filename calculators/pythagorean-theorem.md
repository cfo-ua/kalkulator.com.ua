    <h2>Калькулятор теореми Піфагора онлайн</h2>
    <p>Теорема Піфагора — фундаментальний закон геометрії: <strong>a² + b² = c²</strong>, де a і b — катети, c — гіпотенуза прямокутного трикутника.</p>

    <h3>Як користуватись калькулятором?</h3>
    <p>Введіть довжини двох відомих сторін прямокутного трикутника і натисніть «Обчислити». Калькулятор знайде:</p>
    <ul>
      <li>Невідому сторону трикутника</li>
      <li>Площу трикутника</li>
      <li>Периметр трикутника</li>
      <li>Кути трикутника</li>
    </ul>

    <h3>Типи розрахунків:</h3>
    <ul>
      <li><strong>Знайти гіпотенузу:</strong> c = √(a² + b²)</li>
      <li><strong>Знайти катет a:</strong> a = √(c² - b²)</li>
      <li><strong>Знайти катет b:</strong> b = √(c² - a²)</li>
    </ul>

    <h3>Властивості прямокутного трикутника:</h3>
    <ul>
      <li><strong>Гіпотенуза</strong> — найдовша сторона, протилежна прямому куту</li>
      <li><strong>Катети</strong> — дві коротші сторони, що утворюють прямий кут</li>
      <li><strong>Сума кутів</strong> — завжди 180°, один кут дорівнює 90°</li>
      <li><strong>Площа:</strong> S = (a × b) / 2</li>
    </ul>

    <h3>Де використовується:</h3>
    <ul>
      <li><strong>Будівництво:</strong> розрахунок відстаней, перевірка прямих кутів</li>
      <li><strong>Навігація:</strong> визначення найкоротшого шляху</li>
      <li><strong>Дизайн:</strong> проектування об'єктів, розмітка</li>
      <li><strong>Фізика:</strong> векторні розрахунки, механіка</li>
    </ul>

    <h3>Відомі піфагорові трійки:</h3>
    <p>(3, 4, 5), (5, 12, 13), (8, 15, 17), (7, 24, 25), (20, 21, 29)</p>

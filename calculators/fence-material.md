    <h2>Калькулятор матеріалів для паркану</h2>
    <p>Розрахуйте всі <strong>матеріали</strong>, необхідні для будівництва вашого паркану. Цей комплексний калькулятор оцінює стовпи, секції, лаги, штахети, ворота та кріплення для дерев'яних, металевих, сітчастих та профнастильних парканів.</p>

    <h3>Як розрахувати матеріали для паркану:</h3>
    <ol>
      <li><strong>Виміряйте периметр:</strong> загальна довжина лінії паркану в метрах</li>
      <li><strong>Виберіть висоту паркану:</strong> 1,5 м, 2 м або 2,5 м найпоширеніші</li>
      <li><strong>Оберіть тип паркану:</strong> дерев'яний, профнастил, сітка-рабиця або металевий</li>
      <li><strong>Сплануйте розташування воріт:</strong> додайте ворота та кріплення</li>
    </ol>

    <h3>Стандартні висоти парканів та застосування:</h3>
    <ul>
      <li><strong>1,0-1,2 м:</strong> декоративні, садові межі, зонування</li>
      <li><strong>1,5-1,8 м:</strong> приватність, стандартна висота для житлових ділянок</li>
      <li><strong>2,0-2,5 м:</strong> максимальна приватність, захист від вітру</li>
      <li><strong>Комерційні:</strong> 2,5-3,5 м з елементами безпеки</li>
    </ul>

    <h3>Типи парканів та матеріали:</h3>
    <ul>
      <li><strong>Дерев'яний суцільний:</strong> дошка, штахетник, приватність</li>
      <li><strong>Дерев'яний розрідний:</strong> декоративний, відкритий дизайн</li>
      <li><strong>Профнастил:</strong> низьке обслуговування, різні кольори</li>
      <li><strong>Сітка-рабиця:</strong> безпека, комерційне, утримання тварин</li>
      <li><strong>Металевий кований:</strong> декоративний, довговічний</li>
      <li><strong>Евроштахетник:</strong> металевий, сучасний вигляд</li>
    </ul>

    <h3>Стандарти відстані між стовпами:</h3>
    <ul>
      <li><strong>Дерев'яний паркан:</strong> 2,0-2,5 м між осями</li>
      <li><strong>Профнастил:</strong> 2,0-3,0 м між осями</li>
      <li><strong>Сітка-рабиця:</strong> 2,5-3,0 м між осями</li>
      <li><strong>Важкі ворота:</strong> 1,5-2,0 м між воротними стовпами</li>
    </ul>

    <h3>Вимоги до фундаменту:</h3>
    <ul>
      <li><strong>Ями для стовпів:</strong> 1/3 висоти стовпа + 20 см глибини</li>
      <li><strong>Бетон:</strong> швидкотвердіючий або звичайний, 1-2 мішки на стовп</li>
      <li><strong>Гравійна подушка:</strong> 10-15 см для дренажу</li>
      <li><strong>Розмір стовпів:</strong> 60×60 мм профільна труба, 80×80 мм для воріт</li>
    </ul>

    <h3>Орієнтовні ціни (матеріали за погонний метр):</h3>
    <ul>
      <li><strong>Дерев'яний штахетник:</strong> 800-1500 грн за п.м</li>
      <li><strong>Дерев'яний суцільний:</strong> 1000-2000 грн за п.м</li>
      <li><strong>Профнастил:</strong> 1200-2500 грн за п.м</li>
      <li><strong>Сітка-рабиця:</strong> 400-800 грн за п.м</li>
      <li><strong>Евроштахетник:</strong> 1500-2500 грн за п.м</li>
    </ul>

    <h3>Кріплення та фурнітура:</h3>
    <ul>
      <li><strong>Фурнітура для воріт:</strong> петлі, замки, засуви</li>
      <li><strong>Кронштейни:</strong> кронштейни для лаг, заглушки стовпів</li>
      <li><strong>Кріплення:</strong> оцинковані саморізи, болти, заклепки</li>
      <li><strong>Бетон:</strong> швидкотвердіючий бетон для стовпів</li>
    </ul>

    <h3>Поради з монтажу:</h3>
    <ul>
      <li><strong>Позначте комунікації:</strong> зателефонуйте до служб перед копанням</li>
      <li><strong>Перевірте межі ділянки:</strong> геодезичні мітки та відступи</li>
      <li><strong>Місцеві дозволи:</strong> багато районів вимагають дозволів на паркани</li>
      <li><strong>Координація з сусідами:</strong> обговоріть спільні лінії парканів</li>
    </ul>

    <h3>Вимоги до обслуговування:</h3>
    <ul>
      <li><strong>Дерев'яний паркан:</strong> обробка антисептиком кожні 2-3 роки</li>
      <li><strong>Профнастил:</strong> промивка щорічно, мінімальне обслуговування</li>
      <li><strong>Сітка-рабиця:</strong> перевірка на іржу, заміна пошкоджених секцій</li>
      <li><strong>Металевий паркан:</strong> підфарбовування за потреби</li>
    </ul>

    answer: "Для 30 метрів з відстанню 2,5 м: 13 стовпів (включаючи кутові/кінцеві стовпи). З відстанню 2 м: 16 стовпів. Завжди додавайте один додатковий стовп для кінцевого закінчення."
  - question: На яку глибину закопувати стовпи паркану?
    answer: "Закопуйте на 1/3 висоти стовпа плюс 20 см. Для паркану 2 м: закопуйте на 90 см. У регіонах з промерзанням грунту - нижче рівня промерзання (зазвичай 120+ см)."
  - question: Чи можу я встановити паркан самостійно?
    answer: "Так, з правильними інструментами та плануванням. Дерев'яні та профнастільні паркани підходять для самостійного монтажу. Сітка-рабиця потребує спеціальних інструментів. Розгляньте професіоналів для довгих ділянок."
  - question: Чи потрібен дозвіл на будівництво паркану?
    answer: "Більшість районів вимагають дозволів для парканів вище 2 метрів. Перевірте місцеві будівельні норми щодо обмежень висоти, відступів та потреб у дозволах."
  - question: Який найкращий матеріал для приватності?
    answer: "Дерев'яний суцільний паркан або профнастил найкращі для приватності. Суцільні панелі повністю блокують огляд. Лиственниця найдовговічніша, соснова дошка найекономічніша."
  - question: Скільки коштує встановлення паркану?
    answer: "Професійний монтаж зазвичай подвоює вартість матеріалів. Самостійний монтаж економить 50%, але потребує часу та інструментів. Отримайте кілька цінових пропозицій для професійного монтажу."

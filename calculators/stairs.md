    <h2>Калькулятор сходів</h2>
    <p>Розрахуйте ідеальні <strong>розміри сходів</strong> для безпечних, комфортних та відповідних будівельним нормам сходових маршів. Цей професійний калькулятор визначає висоту сходинки (підйом), глибину проступу (хід) та загальну кількість сходинок.</p>

    <h3>Як використовувати калькулятор сходів:</h3>
    <ol>
      <li><strong>Виміряйте загальний підйом:</strong> вертикальна відстань від нижнього до верхнього поверху</li>
      <li><strong>Виміряйте загальний хід:</strong> горизонтальний простір, доступний для сходів</li>
      <li><strong>Введіть ваші виміри</strong> для отримання оптимальних розмірів сходинок</li>
      <li><strong>Скорегуйте за потреби</strong> відповідно до будівельних норм та стандартів комфорту</li>
    </ol>

    <h3>Стандарти безпечних розмірів сходів:</h3>
    <ul>
      <li><strong>Ідеальна висота підйому:</strong> 15-19 см</li>
      <li><strong>Ідеальна глибина проступу:</strong> 25-28 см</li>
      <li><strong>Максимальний підйом:</strong> 19 см для житлових, 17 см для комерційних</li>
      <li><strong>Мінімальний проступ:</strong> 25 см для житлових, 28 см для комерційних</li>
      <li><strong>Однакові розміри:</strong> всі сходинки мають бути ідентичними ±1 см</li>
    </ul>

    <h3>Вимоги будівельних норм:</h3>
    <ul>
      <li><strong>Висота проходу:</strong> мінімум 2,0 м вертикального просвіту</li>
      <li><strong>Висота поручнів:</strong> 85-95 см над краєм проступу</li>
      <li><strong>Ширина сходів:</strong> мінімум 90 см для житлових</li>
      <li><strong>Майданчики:</strong> обов'язкові зверху та знизу, мінімум 90 см глибиною</li>
    </ul>

    <h3>Формули проектування сходів:</h3>
    <ul>
      <li><strong>Підйом + Хід = 43-46 см</strong> (формула комфортної ходьби)</li>
      <li><strong>2 × Підйом + Хід = 60-64 см</strong> (формула оптимальних пропорцій)</li>
      <li><strong>Кількість сходинок = Загальний підйом ÷ Висота сходинки</strong></li>
      <li><strong>Загальний хід = (Кількість сходинок - 1) × Глибина проступу</strong></li>
    </ul>

    <h3>Поширені застосування сходів:</h3>
    <ul>
      <li><strong>Внутрішні сходи:</strong> основні сходи, доступ до підвалу, горищні сходи</li>
      <li><strong>Зовнішні сходи:</strong> сходи ґанку, сходи терас, садові сходи</li>
      <li><strong>Комерційні сходи:</strong> офісні будівлі, торгові приміщення</li>
      <li><strong>Промислові сходи:</strong> доступ до складів, платформи обладнання</li>
    </ul>

    <h3>Поради з планування матеріалів:</h3>
    <ul>
      <li><strong>Косоури сходів:</strong> зазвичай дошка 50×300 мм для прольотів до 4,2 м</li>
      <li><strong>Проступи:</strong> твердолистяна дошка 32 мм або дошка 50 мм з порожком</li>
      <li><strong>Підйоми:</strong> фанера 18 мм або твердолистяна дошка (може бути відкритим в деяких дизайнах)</li>
      <li><strong>Кріплення:</strong> оцинковані болти, будівельний клей, оздоблювальні цвяхи</li>
    </ul>

    <h3>Типи сходів:</h3>
    <ul>
      <li><strong>Прямі сходи:</strong> найпростіші в будівництві, економні</li>
      <li><strong>Г-подібні сходи:</strong> з поворотом на 90°, з майданчиком</li>
      <li><strong>П-подібні сходи:</strong> з поворотом на 180°, компактні</li>
      <li><strong>Гвинтові сходи:</strong> для обмежених просторів</li>
      <li><strong>Забіжні сходи:</strong> з клиноподібними сходинками на поворотах</li>
    </ul>

faq:
  - question: Яка ідеальна висота сходинки для сходів?
    answer: "Ідеальна висота підйому 15-19 см. Це забезпечує комфортний підйом для більшості людей, відповідаючи будівельним нормам. Нижчі сходинки легше піднімати, але потребують більше сходинок."
  - question: Як розрахувати кількість необхідних сходинок?
    answer: "Поділіть ваш загальний підйом на бажану висоту сходинки. Наприклад: 270 см загальний підйом ÷ 18 см сходинка = 15 сходинок. Потім перерахуйте: 270 см ÷ 15 сходинок = 18 см фактична висота сходинки."
  - question: Що робити, якщо мої сходи не вміщуються в простір?
    answer: "Ви можете: 1) Скорегувати кут сходів (крутіший/пологіший), 2) Додати майданчик для зміни напрямку, 3) Використати забіжні сходинки для поворотів, або 4) Розглянути гвинтові або альтернативні сходи для екстремально обмежених просторів."
  - question: Чи всі сходинки мають бути точно однакового розміру?
    answer: "Так! Будівельні норми вимагають однакової висоти підйому в межах ±1 см та однакової глибини проступу в межах ±1 см. Неоднакові сходинки створюють небезпеку спотикання."
  - question: Чи можу я будувати сходи крутіші за стандартні розміри?
    answer: "Будівельні норми встановлюють максимальну висоту підйому з міркувань безпеки. Для дуже крутого доступу (як корабельні трапи) можливо потрібне спеціальне схвалення або альтернативні рішення."
  - question: Скільки простору потрібно зверху та знизу сходів?
    answer: "Потрібні майданчики мінімум 90 см глибиною зверху та знизу. Ширина майданчика має бути принаймні такою ж широкою, як ширина сходів (мінімум 90 см для житлових)."

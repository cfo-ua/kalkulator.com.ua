    <h2>Калькулятор фарби</h2>
    <p>Розрахуйте точну кількість <strong>фарби</strong>, необхідної для вашого внутрішнього або зовнішнього малярного проекту. Цей професійний калькулятор фарби оцінює необхідні літри, площу покриття та вартість для стін, стель, плінтусів та інше.</p>

    <h3>Як розрахувати покриття фарби:</h3>
    <ol>
      <li><strong>Виміряйте площі стін:</strong> довжина × висота для кожної стіни</li>
      <li><strong>Відніміть отвори:</strong> двері, вікна та великі прилади</li>
      <li><strong>Додайте площу стелі</strong>, якщо фарбуєте стелю</li>
      <li><strong>Виберіть тип фарби</strong> та кількість необхідних шарів</li>
    </ol>

    <h3>Стандартні норми покриття фарби:</h3>
    <ul>
      <li><strong>Преміум фарба:</strong> 10-11 м² на літр</li>
      <li><strong>Стандартна фарба:</strong> 8-10 м² на літр</li>
      <li><strong>Бюджетна фарба:</strong> 7-8 м² на літр</li>
      <li><strong>Грунтовка:</strong> 5-7 м² на літр (варіюється за поверхнею)</li>
      <li><strong>Текстуровані поверхні:</strong> зменшують покриття на 20-30%</li>
    </ul>

    <h3>Коригування покриття за типом поверхні:</h3>
    <ul>
      <li><strong>Гладкий гіпсокартон:</strong> стандартні норми покриття</li>
      <li><strong>Текстуровані стіни:</strong> зменшують покриття на 20-25%</li>
      <li><strong>Шорсткі поверхні:</strong> зменшують покриття на 25-30%</li>
      <li><strong>Раніше пофарбовані:</strong> стандартні норми (якщо схожа кольорова гама)</li>
      <li><strong>Голе дерево/метал:</strong> потребує грунтовки, зменшує покриття на 15%</li>
    </ul>

    <h3>Типи фарб та застосування:</h3>
    <ul>
      <li><strong>Латексна фарба:</strong> легке очищення, швидке висихання, внутрішня/зовнішня</li>
      <li><strong>Олійна фарба:</strong> міцне покриття, довший час висихання</li>
      <li><strong>Грунтовка:</strong> герметизує поверхні, покращує адгезію фарби</li>
      <li><strong>Фарба для стелі:</strong> матове покриття, формула, стійка до бризок</li>
      <li><strong>Фарба для плінтусів:</strong> високий або напівматовий глянець для міцності</li>
    </ul>

    <h3>Професійні поради з фарбування:</h3>
    <ul>
      <li><strong>Купуйте додаткову фарбу:</strong> додайте 10% для підфарбовки та відповідності кольору</li>
      <li><strong>Якість має значення:</strong> краща фарба покриває більшу площу на літр</li>
      <li><strong>Грунтовка коли потрібно:</strong> темні-до-світлих кольорів, голі поверхні</li>
      <li><strong>Кілька тонких шарів:</strong> краще ніж один товстий шар</li>
    </ul>

    <h3>Поради з оцінки вартості:</h3>
    <ul>
      <li><strong>Ціни на фарбу:</strong> 150-500 грн за літр залежно від якості</li>
      <li><strong>Ціни на грунтовку:</strong> 100-300 грн за літр</li>
      <li><strong>Професійна робота:</strong> 50-150 грн за м² залежно від складності</li>
      <li><strong>Витрати на постачання:</strong> пензлі, валики, плівка, стрічка</li>
    </ul>

    <h3>Типові розміри кімнат:</h3>
    <ul>
      <li><strong>Мала спальня:</strong> 3×3,5 м = ~26 м² площі стін</li>
      <li><strong>Вітальня:</strong> 4×5 м = ~36 м² площі стін</li>
      <li><strong>Стандартні двері:</strong> 2 м²</li>
      <li><strong>Стандартне вікно:</strong> 1,5 м²</li>
      <li><strong>Стелі 2,7 м:</strong> найпоширеніша висота житлових приміщень</li>
    </ul>

faq:
  - question: Скільки фарби потрібно для кімнати 3×4 м?
    answer: "Кімната 3×4 м з висотою стелі 2,7 м має близько 42 м² площі стін. Мінус двері/вікна (~5 м²), потрібна фарба для ~37 м². Це вимагає близько 4-5 літрів якісної фарби для одного шару."
  - question: Чи відрізняється покриття грунтовки від покриття фарби?
    answer: "Так, грунтовка зазвичай покриває 5-7 м² на літр проти 8-11 для фарби. Грунтовка товща і призначена для герметизації та підготовки поверхонь, а не для максимального покриття."
  - question: Як розрахувати фарбу для текстурованих стін?
    answer: "Текстуровані стіни поглинають більше фарби. Зменшіть звичайні норми покриття на 20-30%. Якщо стандартне покриття 10 м²/літр, очікуйте 7-8 м²/літр на текстурованих поверхнях."
  - question: Купувати фарбу і грунтовку окремо чи комбіновану?
    answer: "Фарба-і-грунтовка-в-одному працює для незначних змін кольору та раніше пофарбованих поверхонь. Для голих поверхонь, темних-до-світлих кольорів або плям використовуйте окрему грунтовку спочатку."
  - question: Скільки додаткової фарби варто купувати?
    answer: "Купуйте на 10-15% більше фарби для підфарбовки, кольорових варіацій та майбутнього ремонту. Зберігайте залишки фарби з позначкою кімнати та дати для легкого підбору."
  - question: Чи можу я повернути невикористану фарбу?
    answer: "Більшість магазинів приймають повернення невідкритої, незабарвленої фарби. Індивідуальні кольори зазвичай не підлягають поверненню. Перевірте політику магазину перед покупкою великих кількостей."
